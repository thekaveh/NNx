# NNx Poster Wordmark Design

## Goal

Revise the NNx README banner so the artwork identifies the project clearly at repository scale without retaining the unexplained crystal imagery.

## Composition

- Preserve the existing 1983 x 793 panoramic canvas, black background, cyan/blue neural layers, central flare, and left-to-right data flow.
- Remove the complete crystal cluster, floating cubes, and pedestals from the right third.
- Place the exact case-sensitive wordmark `NNx` in the cleared right third.
- Make the wordmark large enough to remain immediately legible when the banner is rendered at README width.
- Use bold geometric letterforms with cyan-white illumination, restrained blue edge glow, and a small number of neural lines or nodes connecting the network to the lettering.
- Treat the wordmark as the network's output, integrated into the scene rather than placed in a label, card, or separate logo panel.

## Invariants

- Do not add a tagline, version, subtitle, badge, watermark, or any text other than `NNx`.
- Do not alter the spelling or capitalization of `NNx`.
- Do not introduce crystals, trophies, coins, blockchain motifs, circuitry chips, robots, brains, or unrelated icons.
- Keep the artwork dark, panoramic, high-contrast, and compatible with the existing README opener.
- Deliver a raster PNG at `docs/assets/nnx-poster.png` with width at least 1200 pixels and aspect ratio at least 2:1.

## Validation

- Inspect the result at full size and at README-like reduced width.
- Confirm that `NNx` is legible, the crystals are absent, and the neural composition remains coherent.
- Run the documentation projection tests and strict MkDocs build after replacing the canonical asset.
