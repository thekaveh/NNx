**Category:** Packaging · **Priority:** P2 · **Size:** M · **Evidence:** read at `9ad461e` (develop)

## Summary

DEC-015: The MPS workflow shares the self-hosted Mac's GPU with programs of one workstation: a lock file under `~/.cache`, ComfyUI on port 8188 and Ollama on port 11434. That coordination has six defects; the worst is that a busy GPU turns the run green with no evidence, a regression of #572's "fails, not skips". The owner must decide whether the coordination leaves the repository (A) or stays and is fixed (B). Both options remove every path by which `mps-evidence` can be skipped.

## Context

**What happens today.** A non-waiting `gpu-check` job probes the lock and the two services, then `mps-evidence` runs only when nothing is busy. The probe (`.github/workflows/mps.yml` L41–L53) counts any `OSError` as "not running":

```python
          def service_busy(url, busy_for):
              # ComfyUI (8188) and Ollama (11434) use the GPU without the lock; a request to
              # either is checked here. An unreachable service is not running; a reply that
              # is not JSON is treated as busy, since its state is unknown.
              try:
                  with urllib.request.urlopen(url, timeout=5) as response:
                      body = response.read()
              except OSError:
                  return False
              try:
                  return busy_for(json.loads(body))
              except ValueError:
                  return True
```

A busy GPU only warns (L79–L82), and `mps-evidence` is then skipped by its `if:` (L98):

```yaml
          echo "busy=$busy" >> "$GITHUB_OUTPUT"
          if [ "$busy" = "true" ]; then
            echo "::warning title=MPS evidence not produced::the GPU lock is held, or ComfyUI or Ollama is busy, so the mps tests were skipped. A skip is not evidence; rerun the workflow once the GPU is free."
          fi
```

```yaml
    if: vars.NNX_MPS_RUNNER == 'true' && (github.event_name != 'pull_request' || github.event.pull_request.head.repo.full_name == github.repository) && needs.gpu-check.outputs.busy == 'false'
```

The defects:

1. **CI-02, the probe reads errors as "idle".** `urllib.error.HTTPError` and `TimeoutError` are `OSError` subclasses, so a ComfyUI or Ollama server that answers 4xx/5xx, or is too slow to answer, counts as not running, and the MPS suite runs on a busy GPU. A JSON list or string body makes `queue.get` raise `AttributeError`, which nothing catches. This contradicts the comment's own rule, "state unknown → busy".
2. **CI-03, a busy GPU gives a green run.** `gpu-check` succeeds and `mps-evidence` is skipped. GitHub reports a job whose `if:` is false as skipped, and a run of successful and skipped jobs is green. The comments say the opposite: "a visible skip, never a pass" (L25–L26) and "It cannot pass by skipping" (L94–L96). CONTRIBUTING L175–L176 says the job "fails on any skip".
3. **CI-04, the services are probed once, before the run, never under the lock.** `scripts/with_mac_gpu_lock.py` takes only the `flock`. The lock is released between jobs, and `uv sync` runs in between, so a ComfyUI job that starts after the probe overlaps the MPS tests.
4. **CI-05, test collection breaks on Windows.** `tests/test_with_mac_gpu_lock.py` L5 runs `import fcntl` before its `repo_file(...)` guard (L13). The sdist ships `tests/`, and NNx supports Windows.
5. **CI-06, pyright skips the script.** `pyrightconfig.json` lists every other top-level script but not `scripts/with_mac_gpu_lock.py`.
6. **DOC-07, CONTRIBUTING §5.2 is stale.** It describes neither `gpu-check`, nor its skip, nor the `NNX_MAC_GPU_LOCK` override.

**Why it matters.** SCOPE-02: the MPS lane is library CI, but which programs share the GPU, on which ports, under which lock path, is a fact about one machine. The probe was added in a31db9d (the lock), ed93d51 (#855, `gpu-check`) and d429011 (#857, the services), with no board issue.

**Background for the worker.**
- Self-hosted runner: the owner's Apple-silicon Mac, registered with the labels `self-hosted, macos, arm64`. Jobs run there only while the repository variable `NNX_MPS_RUNNER` is `true`.
- Repository variable: a plain-text value the owner sets under Settings → Secrets and variables → Actions → Variables. A workflow reads it as `${{ vars.NAME }}`; an unset variable reads as the empty string. A worker cannot set one.
- `gpu-check` / `mps-evidence`: the two self-hosted jobs of `mps.yml`. `gpu-check` probes without waiting and outputs `busy`; `mps-evidence` runs `pytest tests -m mps` with `NNX_REQUIRE_MPS=1`, which makes an `mps` test fail instead of skip without a device (`tests/_mps.py`).
- `mps-gate-without-mps`: the hosted-Linux twin that must see every `mps` test fail. Neither option touches it.
- GPU lock: an advisory exclusive `fcntl.flock` on `~/.cache/mac-gpu.lock` (path overridden by `NNX_MAC_GPU_LOCK`). `scripts/with_mac_gpu_lock.py -- COMMAND` takes it, waits up to `WAIT_SECONDS = 15 * 60`, polls every `POLL_SECONDS = 5` and exits 1 when it gives up. A `flock` taken through a second `open()` of the same file conflicts with the first, even in one process.
- ComfyUI `GET /queue` returns `{"queue_running": [...], "queue_pending": [...]}`; Ollama `GET /api/ps` returns `{"models": [...]}`. Both use the GPU without the lock.
- `urllib` errors: `HTTPError` (the server answered with an error status) subclasses `URLError`, which subclasses `OSError`. A refused connection is `URLError(reason=ConnectionRefusedError)`; a connect timeout is `URLError(reason=TimeoutError)`; a read timeout raises `TimeoutError` itself (`socket.timeout` is an alias of it since Python 3.10).
- `repo_file(...)` (`tests/_repo_files.py`): returns a repository-only path; skips the module in an extracted sdist and fails in a checkout when the file is missing.
- `pytest.importorskip("fcntl")`: imports the module or skips the whole test module. The repository's convention for POSIX-only modules (`tests/test_benchmarking.py` L918: `pytest.importorskip("resource")  # POSIX only`).

   ```python
   """Run one command while holding the shared Mac GPU lock, once ComfyUI and Ollama are idle.

   The MPS workflow runs on a self-hosted Mac that other sessions also use for
   GPU work. Each GPU job takes the same exclusive ``fcntl.flock`` lock on
   ``~/.cache/mac-gpu.lock`` (or ``NNX_MAC_GPU_LOCK``), so two GPU jobs do not
   overlap. The lock is advisory: it only helps when every GPU job takes it.
   ComfyUI (port 8188) and Ollama (port 11434) use the GPU without the lock, so
   while it holds the lock the script also asks them for their state, and waits
   (with the lock released) while either is busy or does not say.

   Usage: ``python3 scripts/with_mac_gpu_lock.py -- COMMAND [ARGS...]``. The
   exit status is the command's. If the lock stays held, or a service stays
   busy, for longer than ``WAIT_SECONDS``, the script exits 1 without running
   the command.
   """

   from __future__ import annotations

   import fcntl
   import json
   import os
   import subprocess
   import sys
   import time
   import urllib.error
   import urllib.request
   from collections.abc import Callable
   from pathlib import Path
   from typing import Any

   WAIT_SECONDS = 15 * 60
   POLL_SECONDS = 5
   COMFYUI_QUEUE_URL = "http://127.0.0.1:8188/queue"
   OLLAMA_PS_URL = "http://127.0.0.1:11434/api/ps"


   def lock_path() -> Path:
       override = os.environ.get("NNX_MAC_GPU_LOCK")
       return Path(override) if override else Path.home() / ".cache" / "mac-gpu.lock"


   def service_busy(url: str, busy_for: Callable[[dict[str, Any]], bool]) -> bool:
       """Whether the local service at ``url`` may be using the GPU. A service
       that refuses the connection or cannot be reached is not running; one that
       answers without stating its state (an HTTP error, a timeout, a body that
       is not a JSON object) counts as busy."""
       try:
           with urllib.request.urlopen(url, timeout=5) as response:
               body = response.read()
       except urllib.error.HTTPError:  # a URLError subclass: caught first
           return True  # it answered, but not with its state
       except TimeoutError:
           return True  # running, too slow to answer
       except urllib.error.URLError as error:
           return isinstance(error.reason, TimeoutError)  # a connect timeout is busy; refused is not running
       except OSError:
           return False
       try:
           state = json.loads(body)
       except ValueError:
           return True
       return busy_for(state) if isinstance(state, dict) else True


   def comfy_busy(queue: dict[str, Any]) -> bool:
       return bool(queue.get("queue_running")) or bool(queue.get("queue_pending"))


   def ollama_busy(loaded: dict[str, Any]) -> bool:
       return bool(loaded.get("models"))


   def services_busy() -> bool:
       return service_busy(COMFYUI_QUEUE_URL, comfy_busy) or service_busy(OLLAMA_PS_URL, ollama_busy)


   def main(argv: list[str]) -> int:
       if argv[:1] == ["--"]:
           argv = argv[1:]
       if not argv:
           print("usage: with_mac_gpu_lock.py -- COMMAND [ARGS...]", file=sys.stderr)
           return 2
       path = lock_path()
       path.parent.mkdir(parents=True, exist_ok=True)
       started = time.monotonic()
       with path.open("a+", encoding="utf-8") as handle:
           while True:
               try:
                   fcntl.flock(handle.fileno(), fcntl.LOCK_EX | fcntl.LOCK_NB)
               except BlockingIOError:
                   waiting_for = f"{path}; another GPU job holds it"
               else:
                   if not services_busy():  # asked while holding the lock, just before the command
                       break
                   fcntl.flock(handle.fileno(), fcntl.LOCK_UN)  # other GPU jobs may take it meanwhile
                   waiting_for = "ComfyUI or Ollama to be idle"
               if time.monotonic() - started > WAIT_SECONDS:
                   print(f"gave up after {WAIT_SECONDS // 60} min waiting for {waiting_for}", file=sys.stderr)
                   return 1
               time.sleep(POLL_SECONDS)
           print(f"holding {path} after {time.monotonic() - started:.0f}s", flush=True)
           # The lock is released when the handle closes, after the command ends.
           return subprocess.call(argv)


   if __name__ == "__main__":
       sys.exit(main(sys.argv[1:]))
   ```

   The lock-busy message is the one the script prints today.
4. Replace the whole of `tests/test_with_mac_gpu_lock.py` with the file below. The two tests that ran a command through a subprocess now call `main` in-process with the service probe replaced, so they never contact a real ComfyUI or Ollama on the machine running the suite; the usage test still runs the script as a subprocess.

   ```python
   """The Mac GPU lock wrapper runs its command under the lock once ComfyUI and Ollama are idle, and fails
   clearly when the GPU stays busy."""

   from __future__ import annotations

   import importlib.util
   import io
   import os
   import subprocess
   import sys
   import urllib.error
   from pathlib import Path

   import pytest

   from tests._repo_files import repo_file

   fcntl = pytest.importorskip("fcntl")  # POSIX only: the sdist ships tests/, and NNx supports Windows

   SCRIPT = repo_file("scripts", "with_mac_gpu_lock.py")


   def _load(tmp_path: Path, monkeypatch: pytest.MonkeyPatch, *, busy=lambda: False):
       """The script as a module: its lock under ``tmp_path``, no polling delay, its service probe ``busy``."""
       spec = importlib.util.spec_from_file_location("with_mac_gpu_lock", SCRIPT)
       assert spec is not None and spec.loader is not None
       module = importlib.util.module_from_spec(spec)
       spec.loader.exec_module(module)
       monkeypatch.setenv("NNX_MAC_GPU_LOCK", str(tmp_path / "mac-gpu.lock"))
       monkeypatch.setattr(module, "services_busy", busy)
       monkeypatch.setattr(module, "POLL_SECONDS", 0)
       return module


   def test_the_command_runs_and_its_status_is_returned(tmp_path, monkeypatch, capsys):
       module = _load(tmp_path, monkeypatch)
       assert module.main(["--", sys.executable, "-c", "import sys; sys.exit(3)"]) == 3
       assert "holding" in capsys.readouterr().out


   def test_the_lock_is_released_after_the_command(tmp_path, monkeypatch):
       module = _load(tmp_path, monkeypatch)
       module.main(["--", sys.executable, "-c", "pass"])
       with (tmp_path / "mac-gpu.lock").open("a+") as handle:
           fcntl.flock(handle.fileno(), fcntl.LOCK_EX | fcntl.LOCK_NB)  # would raise if still held


   def test_a_busy_lock_fails_without_running_the_command(tmp_path, monkeypatch):
       module = _load(tmp_path, monkeypatch)
       monkeypatch.setattr(module, "WAIT_SECONDS", 0)
       marker = tmp_path / "ran"
       with (tmp_path / "mac-gpu.lock").open("a+") as held:
           fcntl.flock(held.fileno(), fcntl.LOCK_EX)
           status = module.main(["--", sys.executable, "-c", f"open({str(marker)!r}, 'w').close()"])
       assert status == 1
       assert not marker.exists()


   def test_a_busy_service_fails_without_running_the_command(tmp_path, monkeypatch, capsys):
       module = _load(tmp_path, monkeypatch, busy=lambda: True)
       monkeypatch.setattr(module, "WAIT_SECONDS", 0)
       marker = tmp_path / "ran"
       status = module.main(["--", sys.executable, "-c", f"open({str(marker)!r}, 'w').close()"])
       assert status == 1 and not marker.exists()
       assert "waiting for ComfyUI or Ollama to be idle" in capsys.readouterr().err


   def test_the_services_are_asked_under_the_lock_and_waited_for(tmp_path, monkeypatch):
       held: list[bool] = []

       def busy_once() -> bool:
           with (tmp_path / "mac-gpu.lock").open("a+") as other:  # a second open: its flock conflicts with ours
               try:
                   fcntl.flock(other.fileno(), fcntl.LOCK_EX | fcntl.LOCK_NB)
               except BlockingIOError:
                   held.append(True)
               else:
                   held.append(False)
           return len(held) == 1  # busy on the first ask, idle on the second

       module = _load(tmp_path, monkeypatch, busy=busy_once)
       assert module.main(["--", sys.executable, "-c", "pass"]) == 0
       assert held == [True, True]  # asked twice, each time while the script held the lock


   @pytest.mark.parametrize(
       ("outcome", "busy"),
       [
           (urllib.error.HTTPError("http://127.0.0.1:8188/queue", 500, "error", None, None), True),
           (urllib.error.URLError(ConnectionRefusedError()), False),
           (urllib.error.URLError(TimeoutError()), True),
           (TimeoutError(), True),
           (b"[]", True),
           (b"not json", True),
           (b'{"queue_running": [], "queue_pending": []}', False),
           (b'{"queue_running": [], "queue_pending": [["job"]]}', True),
       ],
       ids=["http-500", "refused", "connect-timeout", "read-timeout", "json-list", "not-json", "idle", "pending"],
   )
   def test_the_service_probe_counts_an_unknown_state_as_busy(tmp_path, monkeypatch, outcome, busy):
       module = _load(tmp_path, monkeypatch)

       def urlopen(url, timeout):
           if isinstance(outcome, BaseException):
               raise outcome
           return io.BytesIO(outcome)  # a context manager with read(), as urlopen's response is

       monkeypatch.setattr(module.urllib.request, "urlopen", urlopen)
       assert module.service_busy(module.COMFYUI_QUEUE_URL, module.comfy_busy) is busy


   def test_ollama_is_busy_while_a_model_is_loaded(tmp_path, monkeypatch):
       module = _load(tmp_path, monkeypatch)
       assert module.ollama_busy({"models": [{"name": "m"}]}) and not module.ollama_busy({"models": []})


   def test_no_command_is_a_usage_error(tmp_path):
       env = {**os.environ, "NNX_MAC_GPU_LOCK": str(tmp_path / "mac-gpu.lock")}
   ```
