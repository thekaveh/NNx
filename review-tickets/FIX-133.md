## Summary

FIX-133: `fit_temperature` and `select_threshold` now warn (`DeprecationWarning`) when `test_split_id` is omitted, and `select_threshold` refuses a `CalibratedPrediction`'s own calibration split and a source with no rows. The CHANGELOG lists all three; `docs/concepts.md` §18 (calibration) and §19 (abstention) list none. This ticket adds them to those two sections.

## Context

**What happens today.** The warning (`src/nnx/_validation.py` L253–L262), called from `fit_temperature` (`calibration.py` L942) and `select_threshold` (`abstention.py` L1378):

```python
    warnings.warn(
        f"{function}() without test_split_id is deprecated: test_split_id will be required in the next minor "
        "release. Pass the id of the held-out test split (it must differ from split_id).",
        DeprecationWarning,
        stacklevel=3,
    )
```

`select_threshold` also calls `_check_not_calibration_split` (`abstention.py` L239–L242, called at L1380) and refuses zero tuning rows (L1393–L1394), both with `AbstentionError`. CHANGELOG `[Unreleased]` L18, L19 and L33 announce them. `grep -n "deprecat\|calibration_split_id" docs/concepts.md` finds nothing.

**Why it matters.** A user who reads the guide calls the deprecated form, and the next minor release turns it into an error.

**History.** #217 (fitted calibration artifacts) and #218 (abstention policies) wrote §18 and §19 and their split-separation rules; this ticket adds the rules that came after them. The example and test call sites are FIX-144 and FIX-145.

**Background for the worker.**
- `split_id` / `train_split_id` / `test_split_id`: the ids of the split being fitted or tuned on, the training split and the final held-out test split; each must differ.
- `CalibratedPrediction`: the output of a fitted `TemperatureCalibrator`; it records `calibration_split_id`, the split its temperature was fitted on.
- `AbstentionError`: the error type of `nnx.abstention`.

**Proposal.**
1. In `docs/concepts.md` §18, in the **Split separation** bullet, insert after L2535 (`    that note.`) one blank line and:

   ```
       Omitting `test_split_id` (or passing `None`) is deprecated:
       `fit_temperature` and `select_threshold` emit a `DeprecationWarning`,
       and the argument becomes required in the next minor release.
   ```

   (four-space indent, like the paragraph above it).
2. In `docs/concepts.md` §19, replace L2694–L2697 of the **Threshold selection** bullet:

   Old:
   ```
     split**, never the test split. A `split_id` equal to `test_split_id` is
     refused, and a `CalibratedPrediction` needs `input_field=` to say which
     view to tune on. It evaluates every candidate threshold and reports each
     one's counts, coverage and risk.
   ```
   New:
   ```
     split**, never the test split. A `split_id` equal to `test_split_id` is
     refused. So is a `CalibratedPrediction`'s own calibration split
     (`calibration_split_id`, where its temperature was fitted), and a source
     with no rows raises `AbstentionError`. A `CalibratedPrediction` needs
     `input_field=` to say which view to tune on. It evaluates every candidate
     threshold and reports each one's counts, coverage and risk.
   ```

**Worker setup.** No torch needed (docs/config only).
