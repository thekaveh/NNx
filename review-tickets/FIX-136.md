## Summary

FIX-136: Commit 3ed0133 (#853) made three user-visible changes that its message lists but the CHANGELOG does not: an atomic tokenizer write, an atomic GGUF write, and `push_to_hub` refusing non-tensor state before it creates the repository. Separately, `docs/hub.md` and one CHANGELOG entry write `train(resume_from_run_id=...)` / `train(resume_mode=...)`, keyword arguments `NNModel.train` does not take. This ticket adds the three bullets and corrects the two shorthands.

## Context

**What happens today.**
- The three changes are in the code: `GenerativeNNModel._hub_reconstruction_config` writes `tokenizer.json` with `_atomic_write_text` (`generative_nn_model.py` L61–L73: "save() writes through a symlink at tokenizer.json, which could land outside the artifact directory"); `write_gguf` writes through a partial file and renames it (`interop/gguf/writer.py` L255–L260; docstring L213–L214); `_refuse_unloadable_hub_artifact` ends with `_refuse_non_tensor_state(...)` before `create_repo` (`nn_model.py` L4686–L4688). `git log -1 3ed0133` lists all three; `CHANGELOG.md` `[Unreleased]` (L7–L39 at `9ad461e`, L7–L40 at `1402b49`) has none; #859's new `### Fixed` bullet covers the PEFT, net and FAISS saves only.
- `docs/hub.md` L257 (the formats table, "Read by" column): ``train(resume_from_run_id=...)``.
- `CHANGELOG.md` section `[0.4.2]`, the bullet that starts `- **Every resume path refuses a resume point published again while it was read.**` (L168 at `9ad461e`, L169 at `1402b49`): ``NNModel.train(resume_mode="weights_only")``.
- `NNModel.train`'s signature is `train(self, params, callbacks, train_step_fn, eval_step_fn, salt, components, objective, provenance, history, compile, distributed)`; `resume_from_run_id` and `resume_mode` are `NNTrainParams` fields (`nn_train_params.py` L198, L213).

**Why it matters.** Release notes are the record users upgrade by, and a shorthand that looks like a keyword argument sends a reader to a `TypeError`.

**History.** No board issue covers these. Editing the released `[0.4.2]` text is safe for the release tooling: `scripts/release/finalize_changelog.py` only compares `[Unreleased]` entries.

**Background for the worker.**
- `[Unreleased]`: the top section of `CHANGELOG.md`, where every change waiting for the next release goes, under `### Changed`, `### Fixed` or `### Added`.
- `NNTrainParams`: the training configuration passed as `NNModel.train(params=...)`.

**Proposal.**
1. In `CHANGELOG.md` `[Unreleased]` → `### Fixed`, add directly after the bullet ``- `export_state_dict` writes atomically.`` (L28 at `9ad461e`; find it by its text, since #859 added a bullet above it):

   ```
   - **`GenerativeNNModel.save_pretrained` writes `tokenizer.json` atomically.** A symlink at that path is replaced, never written through.
   - **`write_gguf` and `export_ollama_modelfile` write atomically.** A failed write leaves an existing file untouched.
   - **`push_to_hub` refuses non-tensor state before it creates the repository.** Nothing is created or uploaded.
   ```
2. In `docs/hub.md` L257, replace the fragment

   Old: ``| `NNCheckpoint.from_file` / `load`, `train(resume_from_run_id=...)` |``

   New: ``| `NNCheckpoint.from_file` / `load`, `train(NNTrainParams(resume_from_run_id=...))` |``

   (the rest of the row stays).
3. In `CHANGELOG.md` section `[0.4.2]`, in the bullet that starts `- **Every resume path refuses a resume point published again while it was read.**` (L168 at `9ad461e`), replace the fragment

   Old: ``and `NNModel.train(resume_mode="weights_only")`, including``

   New: ``and `NNModel.train` with `NNTrainParams(resume_mode="weights_only")`, including``

**Worker setup.** No torch needed (docs/config only).
