## Summary

FIX-117: `NNTokenizerParams.of` saves the tokenizer to the fixed name `<path>.tmp`, renames it without flushing, and removes `<path>.tmp` in a `finally`. Two concurrent saves to one path collide on that name, a file of that name that belongs to someone else is overwritten and then removed, and a crash can leave an unflushed tokenizer under the final name. Every other NNx writer uses a unique, owned partial file and flushes it before the rename. This ticket writes the tokenizer through `_reserve_partial` / `_commit_partial` / `_discard_partial`.

## Context

**What happens today.** `NNTokenizerParams.of` (`src/nnx/nn/params/nn_tokenizer_params.py` L55–L84) writes through a fixed temporary name (L77–L83):

```python
        tmp = path + ".tmp"
        try:
            cast(Any, tokenizer).save(tmp)
            os.replace(tmp, path)
        finally:
            if os.path.exists(tmp):  # a failed save leaves nothing behind
                os.remove(tmp)
```

- Two processes saving `tok.json` at once write and rename the same `tok.json.tmp`; one may rename the other's half-written file or fail on a vanished name.
- A file named `tok.json.tmp` that NNx did not create is overwritten, then renamed away.
- Nothing flushes the file before `os.replace`, so a power loss can leave a renamed but empty or partial `tok.json`.

(The finding names `NNTokenizerParams.save`; the code is in the `of` factory. There is no `save` method.)

**Why it matters.** A broken `tok.json` makes `NNTokenizerParams.from_state` and every run that records the tokenizer path fail to load. Source: the original tokenizer support; it was missed when the other writers moved to partial files in 3ed0133 (#853).

**History.**
- #260 (FIX-025) set the rule for NNx's writers: "Cleanup never unlinks a path that the helper does not own." The fixed `.tmp` name breaks it.
- #522 (FIX-055) made run listing robust to temporaries left by interrupted saves; a uniquely named, dot-prefixed partial file is the form NNx's other writers leave, and nothing lists it.

**Background for the worker.**
- `_reserve_partial(path)` (`src/nnx/nn/params/nn_run.py`): creates an empty, uniquely named `.<name>.<random>.partial` beside `path` and returns its path. After FIX-116 (this ticket's dependency) it is created with `0o666` under the umask in force, through `_create_exclusive` (`O_EXCL`, `O_NOFOLLOW`).
- `_commit_partial(partial, path)`: gives the partial an existing destination's mode (FIX-116), flushes it through a writable descriptor (`_fsync_file`, FIX-114) and renames it onto `path`.
- `_discard_partial(partial)`: unlinks the partial if it still exists, ignoring `OSError`.
- `tokenizers.Tokenizer.save(path)`: the Rust writer; it opens `path` for writing and truncates it, so it fills the reserved partial in place.
- `nn_run` imports pandas and the history modules; `interop/ollama.py` imports from it lazily for that reason ("lazy: the run module is heavy"), and `interop/gguf/writer.py` L258 does the same for these three helpers.

**Proposal.**
1. In `src/nnx/nn/params/nn_tokenizer_params.py`, `NNTokenizerParams.of`, replace L77–L83 with:

   ```python
           # Lazy: the run module is heavy. A unique partial file beside ``path`` (never a fixed name another save or
           # another program may own), flushed before the rename: an interrupt leaves the previous file, never a
           # truncated or unflushed tokenizer.json under the final name.
           from .nn_run import _commit_partial, _discard_partial, _reserve_partial

           partial = _reserve_partial(path)
           try:
               cast(Any, tokenizer).save(partial)
               _commit_partial(partial, path)
           except BaseException:
               _discard_partial(partial)
               raise
   ```

2. Update the comment above it, L64–L69:

   Old:
   ```python
           # save() is the official HF Rust path — produces the same JSON
           # blob that ``Tokenizer.from_file`` consumes. Write to a temp
           # name and os.replace into place so an interrupt mid-save can't
           # leave a truncated tokenizer.json that from_state can never
           # load (matches the atomic-write convention of NNRun.save /
           # NNCheckpoint.to_file).
   ```
   New:
   ```python
           # save() is the official HF Rust path — produces the same JSON
           # blob that ``Tokenizer.from_file`` consumes. Write to a unique
           # partial file, flush it and rename it into place, so an interrupt
           # mid-save can't leave a truncated tokenizer.json that from_state
           # can never load (the convention of every NNx export).
   ```

   Keep the parent-directory comment and code (L70–L76) unchanged: the directory must exist before `_reserve_partial` creates the partial in it.
3. CHANGELOG: in `## [Unreleased]` → `### Fixed`, add at the end of the list:

   ```
   - **`NNTokenizerParams.of` writes the tokenizer through a unique, flushed partial file.** Two saves to one path no longer share `<path>.tmp`, a file of that name is left alone, and the tokenizer is flushed to stable storage before it is renamed into place.
   ```

4. Tests in `tests/test_tokenizer_params.py`. It imports `os`, `pytest`, `Tokenizer`, `NNTokenizerParams` and `train_bpe` (L12–L20; it skips without `tokenizers`) and defines `_tiny_corpus()` (L23–L30). Add at the end:

   ```python
   class _RecordingTokenizer:
       """Stands in for a Tokenizer in NNTokenizerParams.of, which only calls save(path): records the path it was
       given and writes the real tokenizer there, or fails after a partial write."""

       def __init__(self, tokenizer, fail: bool = False):
           self.tokenizer, self.fail, self.paths = tokenizer, fail, []

       def save(self, path):
           self.paths.append(path)
           if self.fail:
               with open(path, "w", encoding="utf-8") as handle:
                   handle.write("trunc")
               raise RuntimeError("disk full")
           self.tokenizer.save(path)


   def test_of_writes_through_a_unique_flushed_partial_file(tmp_path, monkeypatch):
       import nnx.nn.params.nn_run as nn_run

       flushed = []
       real_fsync_file = nn_run._fsync_file
       monkeypatch.setattr(nn_run, "_fsync_file", lambda path: flushed.append(path) or real_fsync_file(path))
       tk = train_bpe(files=None, vocab_size=64, texts=_tiny_corpus())
       recording = _RecordingTokenizer(tk)
       target = tmp_path / "tok.json"
       NNTokenizerParams.of(tokenizer=recording, path=str(target))
       written = os.path.basename(recording.paths[0])
       assert written.startswith(".tok.json.") and written.endswith(".partial")
       assert flushed == recording.paths  # flushed before the rename
       assert sorted(os.listdir(tmp_path)) == ["tok.json"]
       assert NNTokenizerParams.from_state({"path": str(target)}).vocab_size == tk.get_vocab_size()


   def test_of_leaves_a_file_named_like_the_old_temporary_alone(tmp_path):
       (tmp_path / "tok.json.tmp").write_text("someone else's", encoding="utf-8")
       tk = train_bpe(files=None, vocab_size=64, texts=_tiny_corpus())
       NNTokenizerParams.of(tokenizer=tk, path=str(tmp_path / "tok.json"))
       assert (tmp_path / "tok.json.tmp").read_text(encoding="utf-8") == "someone else's"


   def test_a_failed_save_keeps_the_previous_tokenizer_and_leaves_no_partial(tmp_path):
       tk = train_bpe(files=None, vocab_size=64, texts=_tiny_corpus())
       target = tmp_path / "tok.json"
       NNTokenizerParams.of(tokenizer=tk, path=str(target))
       previous = target.read_bytes()
       with pytest.raises(RuntimeError, match="disk full"):
           NNTokenizerParams.of(tokenizer=_RecordingTokenizer(tk, fail=True), path=str(target))
       assert target.read_bytes() == previous
       assert sorted(os.listdir(tmp_path)) == ["tok.json"]
   ```

   `test_of_creates_parent_directories` (L101–L109) and the other existing tests stay unchanged and must pass.

**Worker setup.** Branch from `develop`. `uv sync --frozen --all-extras` installs torch, `tokenizers` and every extra the tests need.
