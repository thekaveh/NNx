## Summary

FIX-121: Without the `safetensors` package, `nnx.embeddings.export_to_safetensors` writes a `torch.save` pickle to a path the caller usually names `*.safetensors`, and it silently drops non-tensor entries. This ticket makes it always write the safetensors format with NNx's own dependency-free writer (`bundles._save_tensors`), atomically, and refuse non-tensor or unsupported-dtype entries with a `TypeError`. `_save_tensors` gains its first caller in `src/` (DEAD-10).

## Context

**What happens today.** `export_to_safetensors` (`src/nnx/embeddings/faiss_export.py` L169–L218):

```python
    try:
        from safetensors.torch import save_file  # type: ignore[import-not-found]
    except ImportError:
        # No safetensors — plain torch.save fallback. Pickle blob,
        # so reload with torch.load(weights_only=True) on trusted files.
        torch.save(sd, out_path)
        return out_path
```

```python
    for k, v in sd.items():
        if not isinstance(v, torch.Tensor):
            # Skip non-tensor state (rare — schedulers / metadata).
            # The user can save those separately if they need them.
            continue
        cleaned[k] = v.detach().cpu().contiguous().clone()

    save_file(cleaned, out_path)
```

Neither branch is atomic: both write straight to `out_path`.

**Why it matters.** A pickle is not safe to load, which is the reason safetensors exists. A downstream reader that trusts the `.safetensors` name gets a pickle. NNx already ships a writer that produces valid safetensors with no optional dependency: `bundles._tensor_chunks` / `_save_tensors`, used by run bundles (#237).

**History.** #237 (portable run bundles) set the rule: "Unsupported extra state, unknown versions and malformed bundles fail with no pickle or remote fallback." It also made `NNCheckpoint.to_file(format="safetensors")` raise `TypeError` on non-tensor entries; this ticket applies the same rule here.

**Background for the worker.**
- safetensors format: an 8-byte little-endian header length, a JSON header (`dtype`, `shape`, `data_offsets` per tensor, plus `__metadata__`), then the raw tensor bytes. Any safetensors reader opens it.
- `bundles._CODES`: the map from torch dtype to safetensors dtype code that NNx's writer supports (F64, F32, F16, BF16, I64, I32, I16, I8, U8, BOOL, and the float8 types). Complex and unsigned 16/32/64-bit dtypes are not in it.
- `bundles._save_tensors(tensors, metadata) -> bytes`: the whole file as one `bytes` object. `bundles._load_tensors(data, name)`: NNx's reader, used by the tests.
- Partial file: a uniquely named file beside the destination that a writer fills and then renames onto the destination, so a failed write leaves the earlier file intact. Helpers in `src/nnx/nn/params/nn_run.py`: `_reserve_partial(path)` creates it, `_commit_partial(partial, path)` flushes and renames it, `_discard_partial(partial)` removes it. `NNModel.export_state_dict` (`nn_model.py` L5019–L5025) uses this exact pattern.
- Import order: `nnx/__init__.py` imports `bundles` before `embeddings`, and `embeddings/contrastive_trainer.py` already imports `..nn.nn_model` at module level, so module-level imports of `..bundles` and `..nn.params.nn_run` in `faiss_export.py` add no cycle and no import cost.

**Decisions taken here (answering the open questions on this finding).**
- One code path: NNx's writer is used whether or not the `safetensors` package is installed. The output loads with the package's own reader (`test_export_to_safetensors_output_loads_with_the_safetensors_package` keeps checking that).
- The writer stays in `bundles.py`; it is imported, not moved. Moving it to a shared module is Scope: Out.
- A dtype outside `_CODES` raises `TypeError` before anything is written (so `bundles.BundleError` never escapes from this function).

2. Replace the whole body of `export_to_safetensors` after its docstring (L192–L218) with:

   ```python
       out_path = str(out_path)
       sd = backbone.state_dict() if hasattr(backbone, "state_dict") else backbone
       not_tensors = sorted(str(k) for k, v in sd.items() if not isinstance(v, torch.Tensor))
       if not_tensors:
           raise TypeError(
               f"export_to_safetensors writes tensors only; these state entries are not tensors: "
               f"{', '.join(not_tensors)}. Remove them from the state dict, or save them separately."
           )
       unsupported = sorted(f"{k} ({v.dtype})" for k, v in sd.items() if v.dtype not in _CODES)
       if unsupported:
           raise TypeError(f"export_to_safetensors has no safetensors dtype for: {', '.join(unsupported)}")
       data = _save_tensors({str(k): v for k, v in sd.items()}, {})
       # Written beside out_path and renamed onto it only once complete: a failed
       # export leaves an earlier file at out_path intact.
       partial = _reserve_partial(out_path)
       try:
           with open(partial, "wb") as handle:
               handle.write(data)
           _commit_partial(partial, out_path)
       except BaseException:
           _discard_partial(partial)
           raise
       return out_path
   ```

         loaded = _load_tensors(data, "weights")

         assert set(loaded) == set(expected)
         for k in expected:
             assert torch.equal(loaded[k], expected[k])

         out = tmp_path / "weights.safetensors"
