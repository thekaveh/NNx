## Summary

FIX-130: The self-hosted jobs (`mps.yml` `gpu-check` and `mps-evidence`, `docs.yml` `gpu-evidence`) block pull requests from forks only. Dependabot branches live in this repository, so a Dependabot pull request passes the guard and runs `uv sync --frozen --all-extras` and `pytest` with new, unreviewed dependency versions on the maintainer's Mac. This ticket adds a `dependabot[bot]` exclusion to all three `if:` conditions and pins it in the runner test.

## Context

**What happens today.** `.github/workflows/mps.yml` L98 (`mps-evidence`; L29 `gpu-check` and `docs.yml` L64 `gpu-evidence` have the same guard):

```yaml
    if: vars.NNX_MPS_RUNNER == 'true' && (github.event_name != 'pull_request' || github.event.pull_request.head.repo.full_name == github.repository) && needs.gpu-check.outputs.busy == 'false'
    runs-on: [self-hosted, macos, arm64]
```

`mps.yml` triggers on `pull_request` against `main` and `develop`. `.github/dependabot.yml` opens every ecosystem's pull requests against `develop` (`target-branch: develop`, L22, L53, L62) from branches of this repository, so `head.repo.full_name == github.repository` is true for them.

**Why it matters.** The MPS runner is live: it ran this workflow on 2026-11-27, and `NNX_MPS_RUNNER` is set. The next Dependabot pull request installs and executes the new dependency code on that machine before anyone has reviewed it. The runner keeps state between runs (the "Sync the extras" step took 1 s, so `.venv` is reused), and the GPU-lock design (`~/.cache/mac-gpu.lock`) only works if the runner shares the maintainer's home directory. No repository secrets are referenced by these jobs, so the exposure is the machine, not the secrets.

**History.** #572 (FEAT-050) added the MPS lane modelled on the CUDA `gpu-evidence` job of #420: "repository-variable opt-in, no fork pull requests". This ticket extends that rule to Dependabot. #757 (DEC-003) shows Dependabot pull requests are routinely opened against this repository.

**Background for the worker.**
- Self-hosted job: a job whose `runs-on` names `self-hosted`; it runs on a machine the owner registered, not on GitHub's hosted images. `tests/test_ci_runner_image.py` lists them in `SELF_HOSTED` and their opt-in variables in `OPT_IN`.
- `github.event.pull_request.user.login`: the login of the pull request's author; for Dependabot it is `dependabot[bot]`, also after a maintainer pushes to the branch.
- After a Dependabot pull request is merged, the `push` to `develop` runs these jobs as usual; only the unreviewed pull-request run is skipped.

**Note for the owner (not a worker step).** Run the self-hosted runner as a dedicated non-admin macOS user with no access to your home directory, keychain or SSH keys, and register it with `config.sh --ephemeral` so no state survives a run. This ticket closes the Dependabot path; the account split limits any other path.

**Proposal.**
1. In `.github/workflows/mps.yml`, replace L29 with:

   ```yaml
       if: vars.NNX_MPS_RUNNER == 'true' && (github.event_name != 'pull_request' || (github.event.pull_request.head.repo.full_name == github.repository && github.event.pull_request.user.login != 'dependabot[bot]'))
   ```
2. In `.github/workflows/mps.yml`, replace L98 with:

   ```yaml
       if: vars.NNX_MPS_RUNNER == 'true' && (github.event_name != 'pull_request' || (github.event.pull_request.head.repo.full_name == github.repository && github.event.pull_request.user.login != 'dependabot[bot]')) && needs.gpu-check.outputs.busy == 'false'
   ```
3. In `.github/workflows/docs.yml`, replace L64 with:

   ```yaml
       if: vars.NNX_GPU_RUNNER == 'true' && (github.event_name != 'pull_request' || (github.event.pull_request.head.repo.full_name == github.repository && github.event.pull_request.user.login != 'dependabot[bot]'))
   ```
4. Update the comments that state the rule:
   - `mps.yml` L94: Old `    # pull request from a fork never runs on the self-hosted machine. It` → New `    # pull request from a fork or from Dependabot never runs on the self-hosted machine. It`
   - `docs.yml` L60: Old `    # a fork never runs on the self-hosted machine.` → New `    # a fork or from Dependabot never runs on the self-hosted machine.`
   - `CONTRIBUTING.md` L182: Old `and exhaust unified memory. Pull requests from forks never run on it. While the` → New `and exhaust unified memory. Pull requests from forks and from Dependabot never run on it. While the`
5. In `tests/test_ci_runner_image.py::test_the_self_hosted_jobs_exist_and_are_opt_in` (L64–L71), replace the comment and the last assert (L69–L71) with:

   ```python
           # skipped unless its runner is registered, and never for a fork's or Dependabot's pull request
           assert jobs[key]["if"].startswith(f"vars.{OPT_IN[key]} == 'true' && ")
           assert "head.repo.full_name == github.repository" in jobs[key]["if"]
           assert "github.event.pull_request.user.login != 'dependabot[bot]'" in jobs[key]["if"], key
   ```
6. Add to `CHANGELOG.md` under `## [Unreleased]` → `### Fixed`:

   ```
   - **Dependabot pull requests no longer run on the self-hosted GPU and MPS runners.** Those jobs skipped fork pull requests only, so a dependency bump ran its new, unreviewed code on the self-hosted machine; it now runs there only after it is merged.
   ```

**Worker setup.** No torch needed (CI config only). `uv sync --frozen --all-extras` still installs the test dependencies (`pyyaml`).
