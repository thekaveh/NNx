## Summary

FIX-147: Three tests skip when `sentence-transformers` is missing although they never use it, so the floor-dependency lane (no `embeddings` extra) silently skips them. Three more call `pytest.importorskip` on the core dependencies numpy and torch, which the repository's own rule says must fail, never skip, when missing. This ticket removes the six skips.

## Context

**What happens today.**
- `tests/test_paradigm_finite_settings.py` L58, L163 and L199: `pytest.importorskip("sentence_transformers")` at the top of `test_text_contrastive_settings_refuse_non_finite_values`, `test_text_contrastive_settings_refuse_bool_values` and `test_text_contrastive_integer_settings_and_disabled_clipping_are_accepted`. The tests pass `object()` or a local `Embedder` module as the backbone and import only `nnx.embeddings`, which imports without the extra.
- `tests/test_experiment_plan.py` L755: `    np = pytest.importorskip("numpy")`, although `import numpy as np` is at L11.
- `tests/test_named_monitors.py` L1011: `    np = pytest.importorskip("numpy")`.
- `tests/test_params_boundary_validation.py` L724: `    torch = pytest.importorskip("torch")`.
- numpy and torch are core dependencies (`pyproject.toml` `dependencies`, L95–L96: `"torch>=2.4"`, `"numpy>=1.24"`). `tests/test_examples_smoke.py` L80–L82 states the rule: "a broken ``nnx`` import or a missing core dependency fails, never skips".

**Why it matters.** A skipped test is coverage the lane reports but does not have; for core dependencies a skip can hide a broken install.

**History.** #571 fixed four tests that "pass or skip, and the suite exits 0, when the behavior they guard breaks"; these are the same class.

**Background for the worker.**
- `pytest.importorskip(name)`: imports `name` and returns it, or skips the test if the import fails.
- Floor-dependency lane: the CI job that installs only the core dependencies at their minimum versions.
- `tests/test_params_boundary_validation.py` imports torch inside each test (for example `    import torch` at L279), not at module level; follow that style.

**Proposal.**
1. `tests/test_paradigm_finite_settings.py`: delete L58, L163 and L199 (each `    pytest.importorskip("sentence_transformers")`).
2. `tests/test_experiment_plan.py`, `test_a_planned_horizon_without_a_run_to_resume_is_refused_at_validation`: delete L755 (`    np = pytest.importorskip("numpy")`); the module-level `np` (L11) is used instead.
3. `tests/test_named_monitors.py`, `test_monitor_spec_stores_numpy_strings_as_plain_str`: replace L1011

   Old: `    np = pytest.importorskip("numpy")`

   New: `    import numpy as np`
4. `tests/test_params_boundary_validation.py`, `test_link_categories_refuse_a_bare_string`: replace L724

   Old: `    torch = pytest.importorskip("torch")`

   New: `    import torch`
5. No CHANGELOG entry: tests only.

**Worker setup.** Branch from `develop`. `uv sync --frozen --all-extras` installs everything; to see the first three run rather than skip, use an environment without `sentence-transformers` (the floor lane, or `uv pip uninstall sentence-transformers` in a scratch venv).
