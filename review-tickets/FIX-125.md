## Summary

FIX-125: `TeacherRecord` is a frozen dataclass, but its `provenance` is stored as a plain `dict`, so `record.provenance["training_rights"] = "x"` silently changes the record's equality and `state()` while its hash stays the same. This ticket stores provenance as the project's read-only `_FrozenMapping` (from `nnx.trainer.params`), which pickles and deep-copies.

## Context

**What happens today.** `TeacherRecord.__post_init__` (`src/nnx/paradigms/offline_distillation.py` L217) validates provenance and then stores a mutable copy:

```python
        object.__setattr__(self, "provenance", dict(sorted(provenance.items())))
```

`__hash__` (L223–L224) leaves provenance out, and the dataclass `__eq__` includes it, so an edit after construction makes two "equal-hash" records compare unequal and changes what `write_teacher_records` writes.

**Why it matters.** Provenance carries the declared training rights of a teacher record; a frozen record whose rights can be rewritten in place defeats the point of freezing it.

**History.** #558 hit the same problem in the decision benchmark: "Frozen benchmark types such as `Record` hold plain dicts, so `hash()` fails and later edits bypass the strict-JSON check of `Record`." It fixed them with `_FrozenMapping` (`decisions/benchmark.py` L65, L378, L417–L427). #244 introduced `TeacherRecord`. The review proposed `types.MappingProxyType`; it is **not** used here because a `MappingProxyType` cannot be pickled or deep-copied. #558 required both of the frozen benchmark records ("`pickle.loads(pickle.dumps(record)) == record` and `copy.deepcopy(record) == record`"), and `TeacherRecord` keeps the same guarantee.

**Background for the worker.**
- `_FrozenMapping` (`src/nnx/trainer/params.py` L44–L90): an insertion-ordered, read-only `Mapping`. Item assignment and deletion raise `TypeError` (the `Mapping` ABC defines neither). Equality and hash ignore order (#563). `__reduce__` rebuilds it, so `pickle` and `copy.deepcopy` work.
- Import safety: nothing that `nnx.trainer` imports at module level imports `nnx.paradigms` (only `nnx/__init__.py` and `embeddings/contrastive_trainer.py` do), so a module-level import in `offline_distillation.py` adds no cycle; `decisions/benchmark.py` already imports `_FrozenMapping` the same way.
- `TeacherRecord.state()` already returns `dict(self.provenance)`, so the written JSON does not change.

**Proposal.**
1. In `src/nnx/paradigms/offline_distillation.py`, add `from ..trainer.params import _FrozenMapping` to the first-party imports, directly after `from ..objectives import LossTerm, Objective, ObjectiveContext, ObjectiveResult` (L77).
2. Replace L217:

   Old: `        object.__setattr__(self, "provenance", dict(sorted(provenance.items())))`

   New: `        object.__setattr__(self, "provenance", _FrozenMapping(dict(sorted(provenance.items()))))  # read-only (#558)`
3. Replace the `TeacherRecord` class docstring (L149–L150):

   Old:
   ```
       """One stored teacher distribution over a question's candidates (see
       the module docstring). Every field but ``label`` is required."""
   ```
   New:
   ```
       """One stored teacher distribution over a question's candidates (see
       the module docstring). Every field but ``label`` is required.
       ``provenance`` is stored as a read-only mapping sorted by key:
       assigning to it raises ``TypeError``; :meth:`state` emits a plain dict."""
   ```
4. Regenerate the API reference: `uv run python -m scripts.docs.build_api_reference` (`TeacherRecord` is catalogued at `scripts/docs/api_reference_catalog.txt` L969).
5. Add to `CHANGELOG.md` under `## [Unreleased]` → `### Fixed`:

   ```
   - **`TeacherRecord.provenance` is read-only.** The frozen record stored a plain dict, so `record.provenance["training_rights"] = "x"` changed its equality and `state()` while its hash stayed the same; assigning to it now raises `TypeError`. Records still pickle and deep-copy, and `state()` is unchanged.
   ```
6. In `tests/test_offline_distillation.py`, add `import pickle` after `import math`, and add after `test_record_schema`:

   ```python
   def test_record_provenance_is_read_only():
       record = _record("s0", (0.75, 0.25))
       with pytest.raises(TypeError):
           record.provenance["training_rights"] = "x"  # type: ignore[index]
       with pytest.raises(TypeError):
           del record.provenance["source"]  # type: ignore[attr-defined]
       assert record.state()["provenance"] == dict(sorted(PROVENANCE.items()))
       assert type(record.state()["provenance"]) is dict


   def test_a_record_pickles_and_deep_copies_with_read_only_provenance():
       record = _record("s0", (0.75, 0.25), label="cat")
       for copied in (pickle.loads(pickle.dumps(record)), copy.deepcopy(record)):
           assert copied == record and hash(copied) == hash(record)
           assert copied.state() == record.state()
           with pytest.raises(TypeError):
               copied.provenance["x"] = "y"  # type: ignore[index]
   ```
