## Summary

FIX-143: Six comments and docstrings state things the code no longer does: `tests/test_imports.py` claims an exhaustive module list; a QAT comment calls a tuple a dict; `select_linear_slots` omits two of its refusals; the Ollama exporter cites an internal memo name for a write it no longer makes; `finalize_step` says `default_train_step` checks the loss after backward; and `_pickling.py` justifies itself with Python 3.10. This ticket replaces each with accurate text. No code changes.

## Context

**What happens today** (each quoted from `9ad461e`):
1. `tests/test_imports.py` L1–L7 says "every module in nnx imports" and "The full list below is intentionally exhaustive"; 82 of 152 public modules (for example `nnx.calibration`, `nnx.abstention`, `nnx.search`, `nnx.surgery.widen`) are not listed.
2. `src/nnx/quantize/qat.py` L56–L58: `# Supported QAT recipe shortcuts. Keeping this as a small dict (rather` …, but `_SUPPORTED_CONFIGS` (L59) is a `tuple[str, ...]`.
3. `src/nnx/peft/_targets.py`, `select_linear_slots` docstring L92–L94: raises "when ``name_patterns`` is empty or a selected layer is registered in more than one slot". It also raises for a layer whose parent reads its weight directly (`WEIGHT_READING_PARENTS`, L140–L149) and for the `.base` of a `refuse_inside` wrapper (L150–L156).
4. `src/nnx/interop/ollama.py` L165–L170: a six-line comment about `Path.write_text` and the locale code page, ending `` # carries (`feedback_utf8_explicit_text_opens`). `` — an internal memo name. The code below it calls `_atomic_write_text`, which writes UTF-8.
5. `src/nnx/_step_helpers.py`, `finalize_step`, L297–L302: "`default_train_step` checks AFTER for legacy reasons (its tests pin the existing post-step ordering)". But `default_train_step` checks first: `_finite_training_loss_value` (`nn_model.py` L1632–L1643, "Raise before backward/step") runs inside `_record_step_loss` (L3236), before `backward()` (L3254).
6. `src/nnx/nn/params/_pickling.py` L15–L17: "on Python 3.10, ``dataclass(slots=True)`` replaces pickling hooks defined in the class body with its own." `requires-python` is `>=3.11`; on 3.11–3.13 class-body hooks of a `frozen=True, slots=True` dataclass are kept.

**Why it matters.** Each misleads the next person who edits that code; item 4 also leaks a private label into the source.

**History.** #472 repaired documentation across surfaces, and its label scan catches only `[[...]]` links, which is how the bare memo name in item 4 slipped through. #570 cleaned private names from examples. #759 dropped Python 3.10; item 6 is its leftover. DOC-30 is resolved with its option (a) (reword the docstring), not by making the test exhaustive.

**Background for the worker.**
- `_atomic_write_text`: NNx's atomic text writer in `src/nnx/nn/params/nn_run.py`; it opens the file with UTF-8.
- These are comment and docstring edits only; no behaviour changes, so no CHANGELOG entry.

**Proposal.**
1. `tests/test_imports.py`, replace L1–L7:

   Old:
   ```
   """Smoke tests: every module in nnx imports without error.

   This catches broken imports early — most common rot when restructuring.
   The full list below is intentionally exhaustive: when a new module lands
   under src/nnx/, add it here so the next refactor surfaces broken imports
   loudly rather than letting them linger until someone tries to use the
   affected feature.
   ```
   New:
   ```
   """Smoke tests: each subpackage and a sample of modules import without error.

   This catches broken imports early — most common rot when restructuring.
   The list is a sample, not every module in nnx.
   ```
2. `src/nnx/quantize/qat.py` L56: replace `Keeping this as a small dict (rather` with `Keeping this as a small tuple (rather` (the rest of L56–L58 stays).
3. `src/nnx/peft/_targets.py`, replace L92–L94:

   Old:
   ```
       The root module itself is never a slot. Raises ``ValueError`` — before
       any mutation — when ``name_patterns`` is empty or a selected layer is
       registered in more than one slot.
   ```
   New:
   ```
       The root module itself is never a slot. Raises ``ValueError`` — before
       any mutation — when ``name_patterns`` is empty, a selected layer is
       registered in more than one slot, its parent reads its weight directly
       (``WEIGHT_READING_PARENTS``), or it is the ``.base`` of a
       ``refuse_inside`` wrapper.
   ```
4. `src/nnx/interop/ollama.py`, replace the six comment lines L165–L170 (from `    # encoding="utf-8" explicit so a non-ASCII SYSTEM prompt / TEMPLATE` to `` # carries (`feedback_utf8_explicit_text_opens`). ``) with one line:

   ```
       # written atomically, UTF-8, through _atomic_write_text
   ```
5. `src/nnx/_step_helpers.py`, replace L297–L302:

   Old:
   ```
       # Check finiteness BEFORE backward so a diverged loss doesn't
       # propagate NaN/Inf into gradients and (via step()) into the
       # model's weights. `default_train_step` checks AFTER for legacy
       # reasons (its tests pin the existing post-step ordering); the
       # paradigm hooks have no such constraint and we choose the cleaner
       # contract here.
   ```
   New:
   ```
       # Checked before backward, as default_train_step does, so a diverged
       # loss never propagates NaN/Inf into gradients and (via step()) into
       # the model's weights.
   ```
6. `src/nnx/nn/params/_pickling.py`, replace L15–L17:

   Old:
   ```
       order — is unchanged, so new fields must only ever be appended. Attached
       after the class exists: on Python 3.10, ``dataclass(slots=True)``
       replaces pickling hooks defined in the class body with its own.
   ```
   New:
   ```
       order — is unchanged, so new fields must only ever be appended. Attached
       after the class exists: Python 3.10 (no longer supported) replaced
       class-body hooks of a ``dataclass(slots=True)`` with its own, and
       attaching them afterwards works on every version.
   ```
7. Regenerate the API reference in case any of these docstrings is rendered: `uv run python -m scripts.docs.build_api_reference`.

**Worker setup.** No torch needed for the edits; `uv sync --frozen --all-extras` is needed to run the import tests below.
