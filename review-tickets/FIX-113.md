## Summary

FIX-113: When `from_pretrained` loads a directory saved before Hub manifests existed, `_verify_hub_manifest` warns with a hand-picked `stacklevel=3`. The call passes through two `huggingface_hub` frames, so the warning is attributed to a line inside `huggingface_hub`, and Python's default once-per-location filter keys on that library line instead of the caller's. This ticket gives `_warn_at_user_frame` a `skip=` keyword naming the packages to pass over, and uses it with `("nnx", "huggingface_hub")`.

## Context

**What happens today.** `_verify_hub_manifest` (`src/nnx/nn/nn_model.py` L1421–L1451) warns with a fixed stack level (L1428–L1433):

```python
        warnings.warn(
            f"{model_id!r} has no {_HUB_MANIFEST_FILENAME}, so its files load without digest verification; "
            "save it again with this NNx to add one",
            UserWarning,
            stacklevel=3,
        )
```

The call chain is: the user's line → `huggingface_hub`'s `validate_hf_hub_args` wrapper → `ModelHubMixin.from_pretrained` → `NNModel._from_pretrained` (L4904 calls `_verify_hub_manifest`) → `warnings.warn`. `stacklevel=3` therefore names a line in `huggingface_hub/hub_mixin.py`.

`_warn_at_user_frame` (`src/nnx/nn/callbacks.py` L111–L144) walks past every frame whose module is in the `nnx` package, but no further (L127–L129):

```python
    frame = sys._getframe(1)
    while frame.f_back is not None and str(frame.f_globals.get("__name__", "")).split(".")[0] == "nnx":
        frame = frame.f_back
```

**Why it matters.** The user sees the warning attributed to library code, and the once-per-location filter shows it once per process for every caller, not once per caller line. Source: ed93d51 (#855).

**History.** #522 (FIX-055) fixed the same class of failure before, a hand-picked stack level pointing into NNx: its provenance warning now "names the caller's line, not one inside NNx (#522)" (`nn_run._load_provenance_tolerantly`, L724–L737) through `_warn_at_user_frame(..., once_per_location=True)`.

**Background for the worker.**
- `_warn_at_user_frame(message, category=RuntimeWarning, *, once_per_location=False)`: NNx's warning helper. It attributes the warning to the first frame outside `nnx`; with `once_per_location=True` it uses that frame's `__warningregistry__`, so the default filter shows the warning once per caller line. It is imported function-locally at every call site in `nn_model.py` (`from .callbacks import _warn_at_user_frame`, e.g. L648, L756).
- Plan conflict 5: this ticket adds `skip=` to `_warn_at_user_frame` in `nn/callbacks.py`. FEAT-082 later moves the function to a standard-library-only module, `skip=` included.
- `warnings.warn` records the attributed file in `WarningMessage.filename`; a test asserts it equals the test module's `__file__` (precedent: `tests/test_callbacks.py` L634, `tests/test_params_boundary_validation.py` L1341).

**Proposal.**
1. In `src/nnx/nn/callbacks.py`, change the signature of `_warn_at_user_frame` (L111–L113) to:

   ```python
   def _warn_at_user_frame(
       message: str,
       category: type[Warning] = RuntimeWarning,
       *,
       once_per_location: bool = False,
       skip: tuple[str, ...] = ("nnx",),
   ) -> None:
   ```

2. Replace the frame walk (L128) with:

   ```python
       while frame.f_back is not None and str(frame.f_globals.get("__name__", "")).split(".")[0] in skip:
   ```

3. Add to the end of its docstring (before the closing `"""`, L126): "``skip`` names the top-level packages whose frames are passed over (``nnx`` by default); a warning raised under another library's entry point passes that library too, as ``("nnx", "huggingface_hub")`` for ``from_pretrained``."
4. In `src/nnx/nn/nn_model.py`, `_verify_hub_manifest`, replace L1428–L1433 with:

   ```python
           from .callbacks import _warn_at_user_frame

           # The load runs under huggingface_hub's from_pretrained: its frames are passed too, so the warning names
           # the caller's line (and the default filter shows it once per caller line).
           _warn_at_user_frame(
               f"{model_id!r} has no {_HUB_MANIFEST_FILENAME}, so its files load without digest verification; "
               "save it again with this NNx to add one",
               UserWarning,
               once_per_location=True,
               skip=("nnx", "huggingface_hub"),
           )
   ```

   The message text is unchanged. `warnings` stays imported in `nn_model.py` (other call sites use it).
5. CHANGELOG: in `## [Unreleased]` → `### Fixed`, add at the end of the list (after the bullet `- A Ctrl-C held during a body that raises is raised over that exception.`):

   ```
   - **The Hub "no manifest" warning names the caller's line.** `from_pretrained` on a directory saved before manifests existed attributed its `UserWarning` to a line inside `huggingface_hub`, so the default once-per-location filter keyed on library code; it now names the line that called `from_pretrained`.
   ```

6. Tests in `tests/test_hub_manifest.py`. Rewrite `test_a_directory_saved_before_manifests_loads_with_a_warning` (L114–L119) to also check the attribution:

   ```python
   def test_a_directory_saved_before_manifests_loads_with_a_warning(tmp_path):
       _tiny_model().save_pretrained(str(tmp_path))
       (tmp_path / MANIFEST).unlink()
       with pytest.warns(UserWarning, match="nnx_hub_manifest.json") as caught:
           restored = NNModel.from_pretrained(str(tmp_path))
       assert isinstance(restored, NNModel)
       # Attributed to this line, not to huggingface_hub's from_pretrained wrapper.
       assert [w.filename for w in caught if MANIFEST in str(w.message)] == [__file__]
   ```

   Add to the end of `tests/test_callbacks.py` (the module does not import `warnings` at the top, so the test imports it):

   ```python
   def test_warn_at_user_frame_passes_the_packages_it_is_told_to_skip():
       """skip= names the top-level packages whose frames are passed over: by default the warning names this
       file; with this module's own package skipped too, it names the frame that called the test."""
       import warnings

       from nnx.nn.callbacks import _warn_at_user_frame

       with warnings.catch_warnings(record=True) as caught:
           warnings.simplefilter("always")
           _warn_at_user_frame("by default", UserWarning)
       assert [w.filename for w in caught] == [__file__]
       with warnings.catch_warnings(record=True) as caught:
           warnings.simplefilter("always")
           _warn_at_user_frame("past this module", UserWarning, skip=("nnx", __name__.split(".")[0]))
       assert len(caught) == 1 and caught[0].filename != __file__
   ```

   The second call skips this test module's own top-level package (`tests`), so the attributed frame is the pytest frame that called the test.
