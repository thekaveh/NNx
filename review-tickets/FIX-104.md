## Summary

FIX-104: Since 3ed0133 (#853), `evaluate()` fingerprints every sample input for the report's `sample_set`, and one input with no stable digest (a dict holding `np.float32`, a list holding NaN, `bytes`, a list of tensors, text with a lone surrogate) makes the whole call raise `BenchmarkError`, so no report is produced. NNx 0.5.0 scored the same samples. This ticket scores them again: the report records no `sample_set` and `evaluate()` warns, naming the sample.

## Context

**What happens today.** `_input_digest` turns `_fingerprint`'s refusal into a fatal error (`src/nnx/decisions/benchmark.py` L1298–L1304):

```python
def _input_digest(sample: Sample) -> str:
    """The digest of a sample's input, for the sample set: a report that
    cannot fingerprint its inputs cannot say which samples it scored."""
    try:
        return _fingerprint(sample.input)
    except BenchmarkError as error:
        raise BenchmarkError(f"sample {sample.id!r} cannot be fingerprinted for the report: {error}") from error
```

`_sample_set` calls it for every sample (L1313–L1332), and `evaluate` calls `_sample_set(samples)` at L1292, after every slice was computed. `_fingerprint` (L205–L242) handles only `str`, `tuple`, tensors, non-object ndarrays and strict JSON (`allow_nan=False`); anything else raises `BenchmarkError(... "; pass id=")`. That advice cannot help here: the `Sample` already has an id. `collect()` never fingerprints, so the same samples collect fine and fail only at replay. `Sample.input` is typed `Any`.

**Why it matters.** A user's whole replay fails on one sample, after every slice was computed, with advice that does not apply. Source: 3ed0133 (#853, "Benchmark comparisons include sample inputs").

**History.**
- #557 made custom inputs a served case: "With a provider that has no `check()`, `DecisionJob.run` and `arun` answer for a state of non-text, non-tensor rows". `collect` serves them too. `evaluate` must not be the one entry point that refuses them.
- #557 also made the lone-surrogate refusal deliberate for *derived* sample ids: "`rewrite_input` / `add_context` with a lone surrogate in the text input raise `BenchmarkError`". That refusal stays: `_derived` and the perturbation helpers keep calling `_fingerprint` unchanged.
- #243 defined the comparison contract: "Comparison import rejects a mismatched split or metric identity." The sample-set check came later and is already skipped when either report records none (`compare_reports`, L1616–L1620: `if None not in sets and sets[0] != sets[1]`).

**Background for the worker.**
- `Sample`: one benchmark item (`id`, `question`, `input`, `label`, slicing fields). `Record`: one provider answer, joined to a sample by id and question digest.
- `evaluate(samples, records, split=...)`: replays records into a `BenchmarkReport`; it calls no provider.
- `sample_set`: an optional field of `BenchmarkReport` (L1464), a SHA-256 over every sample's id, question digest, input digest, label and slicing. `compare_reports` refuses two reports whose sample sets differ; it skips the check when either is `None`.
- `_fingerprint(value)`: the process-stable digest of one input; it raises `BenchmarkError` for an input it cannot digest. Its other caller is `_derived` (L251), which builds perturbed-sample ids; that caller's "pass id=" advice is correct and stays.
- `stacklevel=3` in `warnings.warn` inside `_sample_set` points at the line that called `evaluate()` (frame 1 `_sample_set`, frame 2 `evaluate`, frame 3 the caller).

**Proposal.**
1. In `src/nnx/decisions/benchmark.py`, add `import warnings` after `import time` (L58).
2. Replace `_input_digest` (L1298–L1304) with:

   ```python
   def _input_digest(sample: Sample) -> Optional[str]:
       """The digest of a sample's input, for the sample set, or ``None`` when
       the input has no stable digest (``_fingerprint`` refuses it): the sample
       is still scored, and the report then records no sample set."""
       try:
           return _fingerprint(sample.input)
       except BenchmarkError:
           return None
   ```

3. Replace `_sample_set` (L1313–L1332) with the version below. The JSON row keeps the same eight fields in the same order, so every digest a fingerprintable sample set gives today stays byte-identical:

   ```python
   def _sample_set(samples: Sequence[Sample]) -> Optional[str]:
       """Which samples a report scored — their ids, question digests, inputs,
       labels and slicing (family, held-out, perturbation, grouping unit) —
       order-free; ``None``, with a ``UserWarning`` naming the first such
       sample, when an input has no stable digest."""
       digests = [_input_digest(sample) for sample in samples]
       unstable = [sample.id for sample, digest in zip(samples, digests, strict=True) if digest is None]
       if unstable:
           # stacklevel=3: the line that called evaluate(), which calls this function.
           warnings.warn(
               f"evaluate(): the input of sample {unstable[0]!r} ({len(unstable)} of {len(samples)} samples) has no "
               "stable digest, so the report records no sample_set and compare_reports cannot check that two "
               "reports scored the same samples",
               UserWarning,
               stacklevel=3,
           )
           return None
       rows = sorted(
           json.dumps(
               [
                   sample.id,
                   sample.digest,
                   digest,
                   sample.true_label,
                   sample.family,
                   sample.heldout,
                   sample.perturbation,
                   sample.unit,
               ]
           )
           for sample, digest in zip(samples, digests, strict=True)
       )
       return "sha256:" + hashlib.sha256("\n".join(rows).encode("utf-8")).hexdigest()
   ```

4. Do not change `_fingerprint`, `_derived`, `Sample.__post_init__` (validating inputs there would break users who only call `collect()`), `compare_reports` or `BenchmarkReport`. `BenchmarkReport.sample_set` is already `Optional[str]`.
5. In the `evaluate` docstring, insert this paragraph between the first paragraph (ending "Calls no provider and fits nothing.", L1239) and `Args:`:

   ```
       The report's ``sample_set`` digests the samples' ids, question digests,
       inputs, labels and slicing. When a sample's input has no stable digest
       (text holding a lone surrogate, or a value JSON cannot hold: a NumPy
       scalar, NaN, ``bytes``, a list of tensors) the samples are still
       scored, the report records no ``sample_set`` and a ``UserWarning``
       names the first such sample; :func:`compare_reports` then cannot check
       that two reports scored the same samples.
   ```

6. In `docs/decisions.md` §8, replace L553–L554:

   Old:
   ```
     sample's input is a text, a tensor or array, or a tuple of them (several
     inputs per sample, batched part by part).
   ```
   New:
   ```
     sample's input is a text, a tensor or array, or a tuple of them (several
     inputs per sample, batched part by part). When a sample's input has no
     stable digest (text holding a lone surrogate, a value JSON cannot hold
     such as a NumPy `float32` scalar or `bytes`, or a list holding NaN),
     `evaluate` still scores it but warns (`UserWarning`), and the report
     records no sample set, so `compare_reports` cannot check that two
     reports scored the same samples.
   ```

7. Regenerate the API reference: `uv run python -m scripts.docs.build_api_reference` (the `evaluate` docstring is in `docs/api.md`).


9. Tests in `tests/test_decision_benchmark.py`. The module already imports `numpy as np`, `pytest`, `torch`, `Sample`, `evaluate`, `compare_reports` and defines `fixture()`, `AB` and `metric()` (L48–L69).
   - **Rewrite** `test_evaluate_names_a_sample_whose_input_has_no_stable_digest` (L1349–L1353). It enshrines the bug (`pytest.raises(BenchmarkError, match="'s0' cannot be fingerprinted")`). New body:

     ```python
     def test_evaluate_names_a_sample_whose_input_has_no_stable_digest():
         """NNx 0.5.0 scored such samples; the sample-set digest made evaluate() fail on them. The report now
         records no sample set, and the warning names the sample and the caller's line."""
         samples, records = fixture()
         opaque = [Sample(samples[0].id, AB, object(), "a")] + samples[1:]
         with pytest.warns(UserWarning, match=r"the input of sample 's0' \(1 of 4 samples\) has no stable digest") as caught:
             report = evaluate(opaque, records, split="x")
         assert [w.filename for w in caught if "no stable digest" in str(w.message)] == [__file__]
         assert report.sample_set is None
         assert metric(report, "accuracy").value == pytest.approx(0.75)
         assert report.slices["in_family"].coverage.eligible == 4
     ```

   - **Add**, directly after it:

     ```python
     @pytest.mark.parametrize(
         "value",
         [{"x": np.float32(1.0)}, [1.0, float("nan")], b"raw bytes", [torch.zeros(2)], "lone \ud83d surrogate"],
         ids=["numpy-scalar-dict", "nan-list", "bytes", "tensor-list", "lone-surrogate"],
     )
     def test_evaluate_scores_samples_whose_inputs_have_no_stable_digest(value):
         samples, records = fixture()
         odd = [Sample(s.id, s.question, value, s.label) for s in samples]
         with pytest.warns(UserWarning, match="no stable digest"):
             report = evaluate(odd, records, split="x")
         assert report.sample_set is None
         assert metric(report, "accuracy").value == pytest.approx(0.75)
         deltas = compare_reports(report, report)
         assert all(delta in (0.0, None) for row in deltas.values() for delta in row.values())
     ```

   - `test_sample_set_follows_the_input_text` (L1315) and `test_generators_exports_and_sample_sets` (L776) stay unchanged and must pass: a fingerprintable sample set keeps its digest and its refusal.
