**Category:** Persistence · **Priority:** P1 · **Size:** M · **Evidence:** read at `9ad461e` (develop); not run: torch was unavailable in the review environment

## Summary

FIX-109: ed93d51 (#855) added a save-side portability rule (Windows drops a trailing space or dot, so `run.` names `run` there) to `_validate_run_id`, which every reader calls. Directories such as `runs/exp1.` are legal on Linux and macOS and exist from NNx 0.5.0, so one of them makes `NNRun.all()` fail, makes `runs/best` unreadable when it points there, and makes the next save move `runs/best` away from it for good. This ticket applies the rule to reads only on Windows, keeps it on every platform for `NNCheckpoint.save` through a new `_validate_new_run_id`, and makes `NNRun.all()` skip a directory no reader can open by its name.

## Context

**What happens today.** The rule sits in the one validator every reader uses (`src/nnx/nn/params/nn_run.py` L199–L202):

```python
    # Windows drops a trailing space or dot from a path component, so "run." and ".. " name "run" and ".." there:
    # refuse them here, where the id still says what it names.
    if run_id[-1] in " ." or not run_id.strip() or run_id.strip() == "..":
        raise ValueError(f"run id must not end in a space or a dot, or be empty or `..` once stripped; got {run_id!r}")
```

Three things go wrong with a legacy `runs/exp1.`:
1. `NNRun.all()` (L1400–L1411) filters entries with `_is_run_entry` (L436–L447), which never checks the id, then calls `NNRun.load(entry)`, which raises `ValueError`: the whole listing fails.
2. `NNRun.best_id()` (L1296–L1306) can return `exp1.`, which every reader then refuses: `NNRun.load("best")`, `NNCheckpoint.load(run="best")`, `load_provenance`, resume (`_resolve_run_id`, L599–L610: `return None if best is None else _validate_run_id(best)`).
3. `_committed_best_checkpoint` (L644–L683) wraps `NNRun._load` in `except Exception: return None`, so the legacy best run looks ineligible, and the next save of any run moves `runs/best` away from it silently (`_update_best_pointer`, L1270–L1276).

**Why it matters.** Upgrading NNx makes existing runs unlistable and silently loses the best pointer. Source: ed93d51 (#855); CHANGELOG `[Unreleased]` L29.

**History.**
- #546 (FIX-078) fixed the same class of regression by scoping the rule: "Runs saved by nnx 0.4.1 with another kind and `warmup_steps > total_steps` no longer load, fail `NNRun.all()` and silently lose the `runs/best` pointer on the next save." Its acceptance criterion is the model for this one: "An NNModel run ... loads through `NNRun.load`, `NNRun.load("best")` and `NNRun.all()`, with id and `state()` unchanged. It stays `runs/best` after a worse run is saved."
- #522 (FIX-055) made `_is_run_entry` the one predicate `NNRun.all` and the `runs/best` election share ("so neither sees a run twice through a stale alias"). This ticket extends that predicate; it does not add a second one. Its tests in `tests/test_best_pointer_readers.py` (L366–L411) must keep passing.

**Background for the worker.**
- Run id: the name of a run's directory under `runs/`. NNx writes the 32-character MD5 hex of the run's state; users choose any id through `NNCheckpoint.save(run=...)`.
- `runs/best`: a symlink (or a `best/POINTER.txt` directory where symlinks fail) naming the run with the lowest BEST-checkpoint error. `_update_best_pointer` maintains it on every `NNRun.save`.
- Read site: a caller that opens an existing run by id. Create site: a caller that names a new run directory.
- `_ON_WINDOWS`: a new module constant (`os.name == "nt"`), so tests can switch the rule without touching `os.name`.

**Every `_validate_run_id` caller at 9ad461e, classified.** Only one create site is reachable with a user-chosen id; everything else reads.

**Proposal.**
1. In `src/nnx/nn/params/nn_run.py`, add before `_validate_run_id` (L174):

   ```python
   # Windows drops a trailing space or dot from a path component, so there "run." and ".. " name "run" and "..".
   _ON_WINDOWS = os.name == "nt"


   def _refuse_windows_alias(run_id: str) -> None:
       """Refuse a run id that Windows would read as another directory's name:
       one that ends in a space or a dot, or is empty or ``..`` once stripped."""
       if run_id[-1] in " ." or not run_id.strip() or run_id.strip() == "..":
           raise ValueError(f"run id must not end in a space or a dot, or be empty or `..` once stripped; got {run_id!r}")
   ```

2. In `_validate_run_id`, replace L199–L202 with:

   ```python
       # A read refuses a Windows alias only on Windows, where it names another directory. Linux and macOS hold such
       # directories (NNx 0.5.0 saved them), which keep loading; a new run id is refused everywhere (_validate_new_run_id).
       if _ON_WINDOWS:
           _refuse_windows_alias(run_id)
   ```

   and add to its docstring, after "Accepts: any non-empty string that is its own basename (no path separators, no `..`, no embedded null).": "On Windows it also refuses an id that ends in a space or a dot, or is empty or `..` once stripped; :func:`_validate_new_run_id` refuses those on every platform."
3. Add after `_validate_run_id`:

   ```python
   def _validate_new_run_id(run_id: str) -> str:
       """:func:`_validate_run_id` for an id that names a run a save writes:
       a Windows alias (a trailing space or dot, or empty or ``..`` once
       stripped) is refused on every platform, so the run reads as itself
       wherever it is copied."""
       _validate_run_id(run_id)
       _refuse_windows_alias(run_id)
       return run_id
   ```

4. In `_is_run_entry` (L436–L447), after the `if entry.startswith(".") or ...: return False` line, add:

   ```python
       try:
           _validate_run_id(entry)
       except ValueError:
           return False  # no reader opens it by this name (glob characters; a Windows alias on Windows)
   ```

   `NNRun.all`, `NNRun.best_id` and the `runs/best` election (`_committed_best_checkpoint`) all go through `_is_run_entry`, so they keep agreeing. Add to its docstring, after "or a dot-name (``.leases``, locks).": "A name no reader accepts as a run id (glob characters; on Windows, a trailing space or dot) is no run either."
5. In `src/nnx/nn/params/nn_checkpoint.py`, change `_checkpoint_path` (L85–L113):
   - signature: `def _checkpoint_path(run: str, type: Checkpoints, root: Optional[str] = None, *, new: bool = False) -> str:`
   - replace the import and call (L100–L102):

     Old:
     ```python
         from .nn_run import _validate_run_id

         _validate_run_id(run)
     ```
     New:
     ```python
         from .nn_run import _validate_new_run_id, _validate_run_id

         # A save (new=True) writes the run: its id must read as itself on every platform. A read opens what exists.
         (_validate_new_run_id if new else _validate_run_id)(run)
     ```
   - add to its docstring: "``new=True`` (``NNCheckpoint.save``) also refuses, on every platform, a run id Windows would read as another directory's name (:func:`nnx.nn.params.nn_run._validate_new_run_id`)."
6. In `NNCheckpoint.save`, change L753 `ckpt_path = _checkpoint_path(run, type, root=root)` to `ckpt_path = _checkpoint_path(run, type, root=root, new=True)`, and add this sentence to the end of its docstring's second paragraph, the one that ends "rides in the training state." (L724–L726): "A ``run`` that ends in a space or a dot, or is empty or ``..`` once stripped, is refused with ``ValueError`` before anything is written: Windows would read it as another directory's name."
7. Regenerate the API reference: `uv run python -m scripts.docs.build_api_reference` (the `NNCheckpoint.save` docstring is in `docs/api.md`).
8. CHANGELOG: in `## [Unreleased]` → `### Fixed`, replace L29:

   Old:
   ```
   - A run id that Windows would normalise (a trailing dot or space, or `..`) is refused.
   ```
   New:
   ```
   - **A new run id that Windows would normalise is refused; existing runs keep loading.** `NNCheckpoint.save` refuses a run id ending in a dot or a space, or empty or `..` once stripped, on every platform. Readers refuse such an id only on Windows, where it names another directory, so runs NNx 0.5.0 saved under such ids on Linux and macOS still list, load and keep the `runs/best` pointer. `NNRun.all()` skips a directory whose name is no valid run id instead of failing.
   ```

9. Tests.
   - `tests/test_pass2_r_series.py::test_t7_run_id_refuses_a_name_windows_would_normalise` (L381–L387) enshrines the read-side refusal. Change its import and call from `_validate_run_id` to `_validate_new_run_id` (the parametrisation and the `match=` stay). Add after it:

     ```python
     @pytest.mark.parametrize("run_id", [".. ", "run.", "run ", " ", "..."])
     def test_t7_a_read_refuses_a_name_windows_would_normalise_only_on_windows(run_id, monkeypatch):
         """A read opens a run that exists: such an id names another directory only on Windows, and runs NNx 0.5.0
         saved under it on Linux and macOS keep loading."""
         from nnx.nn.params import nn_run

         monkeypatch.setattr(nn_run, "_ON_WINDOWS", False)
         assert nn_run._validate_run_id(run_id) == run_id
         monkeypatch.setattr(nn_run, "_ON_WINDOWS", True)
         with pytest.raises(ValueError, match="must not end in a space or a dot"):
             nn_run._validate_run_id(run_id)
     ```

   - `tests/test_best_pointer_readers.py`: add at the end of the module. They use the module's `runs` fixture (L94–L102: the template's model and trainer runs copied under `tmp_path`, the cwd, and `point(layout, target)`), `LAYOUTS`, `NNRun`, `NNCheckpoint`, `Checkpoints`, `os` and `shutil`, all already imported.

     ```python
     @pytest.mark.skipif(os.name == "nt", reason="Windows cannot hold a directory whose name ends in a dot")
     @pytest.mark.parametrize("layout", LAYOUTS)
     def test_a_legacy_run_with_a_trailing_dot_lists_loads_and_stays_best(runs, tmp_path, layout):
         """NNx 0.5.0 saved checkpoints under any run id, so runs/legacy. exists on Linux and macOS. The Windows rule
         refused it on every read: NNRun.all() failed, a pointer to it could not be read, and the next save moved
         runs/best away from it for good."""
         model_id, _, point = runs
         shutil.copytree(tmp_path / "runs" / model_id, tmp_path / "runs" / "legacy.")
         assert len(NNRun.all()) == 3  # the model run, the trainer run and legacy.
         assert NNRun.load("legacy.").state() == NNRun.load(model_id).state()
         point(layout, "legacy.")
         assert NNRun.best_id() == "legacy."
         assert NNRun.load("best").state() == NNRun.load(model_id).state()
         own = NNCheckpoint.load(run="legacy.", type=Checkpoints.LAST).training_state_id
         assert NNCheckpoint.load(run="best", type=Checkpoints.LAST).training_state_id == own
         NNRun.load(model_id).save()  # an equally good run's save keeps the incumbent
         assert NNRun.best_id() == "legacy."


     @pytest.mark.skipif(os.name == "nt", reason="Windows cannot hold a directory whose name holds '*'")
     def test_a_run_directory_whose_name_is_no_valid_run_id_is_not_listed(runs, tmp_path):
         model_id, trainer_id, _ = runs
         shutil.copytree(tmp_path / "runs" / model_id, tmp_path / "runs" / "copy*")
         assert sorted(run.id for run in NNRun.all()) == sorted([model_id, trainer_id])


     @pytest.mark.parametrize("run_id", ["new.", "new ", "..."])
     def test_a_checkpoint_save_refuses_a_new_run_id_windows_would_normalise(runs, tmp_path, run_id):
         model_id, _, _ = runs
         checkpoint = NNCheckpoint.load(run=model_id, type=Checkpoints.LAST)
         before = sorted(os.listdir(tmp_path / "runs"))
         with pytest.raises(ValueError, match="must not end in a space or a dot"):
             checkpoint.save(run=run_id, type=Checkpoints.LAST)
         assert sorted(os.listdir(tmp_path / "runs")) == before
     ```
