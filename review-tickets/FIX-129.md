## Summary

FIX-129: The FAISS, Captum, torchinfo, Netron, onnxscript and Hub (`huggingface_hub`, `safetensors`) guards catch every `ImportError` and say "install the extra", so a broken install is reported as missing. The Hub message is written out six times. This ticket (part 3 of 3) routes each through `nnx._optional.require` / `require_onnxscript` (FIX-127). Every hint fragment a test asserts is kept, and no existing test changes.

## Context

**What happens today.** For example `netron_export` (`src/nnx/viz/netron.py` L117–L123):

```python
        try:
            import netron  # type: ignore[import-not-found]
        except ImportError as e:
            raise ImportError(
                "netron_export(launch=True) requires the `netron` package. "
                "Install via `pip install thekaveh-nnx[viz-interactive]` (or `pip install netron`)."
            ) from e
```

The same catch-all shape is in `embeddings/faiss_export._import_faiss` (L39–L49 at `9ad461e`, L40–L50 at `1402b49`), `viz/attribute._build_attributor` (L50–L63), `viz/summary.summary` (L72–L77), `NNModel.to_onnx` for onnxscript (`nn_model.py` L4280–L4286), `NNModel._save_pretrained` (L4734–L4737), `NNModel._from_pretrained` (L4881–L4884) and `NNCheckpoint`'s safetensors writer and reader (`nn_checkpoint.py` L642–L647, L1211–L1216). Without `huggingface_hub`, `nn_model.py` installs a stub mixin (L148–L176) whose methods raise a fixed "requires the `hub` extra" message, even when the package is installed but broken.

**Why it matters.** As in FIX-128: a broken install's real cause is hidden behind an instruction to install what is already there.

**History.** #249 set `require`'s rule ("An `ImportError` raised inside an installed dependency keeps its original cause"). #234 pinned the wording (lead with `pip install "thekaveh-nnx[<extra>]"`). #570 made `to_onnx` and `netron_export` name `thekaveh-nnx[onnx]` through `require_onnx`; this ticket does the same for the dynamo path and the viewer.

**Background for the worker.**
- `require(module, feature) -> ModuleType` and `require_onnxscript(feature)` (`src/nnx/_optional.py`, FIX-127): a missing registered package raises `ImportError("<feature> needs <package>: pip install \"thekaveh-nnx[<extra>]\" (or pip install <requirement>)")`; any other failure propagates unchanged.
- Hub stub: when `from huggingface_hub import PyTorchModelHubMixin` fails at `import nnx`, `NNModel` subclasses a stub `_HubMixinBase` instead, so `import nnx` still works. The import stays a catch-all there (a broken Hub install must not break `import nnx`); the stub now calls `require` at call time, which raises the "missing" hint or re-raises the broken install's own error.
- `NNModel` overrides `save_pretrained` and `push_to_hub` (they end in the mixin's method) but not `from_pretrained`, so `NNModel.from_pretrained(...)` reaches the stub directly.
- Simulating a missing package in a test: `monkeypatch.setitem(sys.modules, "pkg", None)` (in process), or `tests/test_core_install.py`'s `_run(code, blocked=(...), tmp_path=...)`, which runs `code` in a fresh interpreter whose import system refuses the listed packages.

Replace `_import_faiss` (L32–L50 at `9ad461e`, L33–L51 at `1402b49`) with:

   ```python
   def _import_faiss():
       """Import faiss on use (:func:`nnx._optional.require`).

       Keeping the import inside the call site means ``import
       nnx.embeddings`` doesn't blow up when the optional FAISS extra
       isn't installed — only the actual export call does. A missing
       ``faiss`` raises an ``ImportError`` naming the ``embeddings`` extra;
       an installed one that fails to import raises its own error.
       """
       return require("faiss", "export_to_faiss")
   ```

     ```python
     except ImportError:  # pragma: no cover — gated by optional dep
         # A broken install must not break `import nnx`: the stub defers to require() at call time.
         _HUB_IMPORTED_LATE = "huggingface_hub became importable after nnx was imported; restart Python to use the Hub"

         class _HubMixinBase:
             """No-op stub installed when ``huggingface_hub`` could not be imported.

             Any attempt to call save_pretrained / from_pretrained / push_to_hub
             raises the ImportError :func:`nnx._optional.require` gives: one
             naming the ``thekaveh-nnx[hub]`` extra when the package is
             missing, or an installed package's own import error.
             """

             _optional_stub = True  # the API reference renders the real mixin's methods only

             def _hub_unavailable(self) -> NNModel:
                 require("huggingface_hub", "Hugging Face Hub integration")
                 raise ImportError(_HUB_IMPORTED_LATE)

             def save_pretrained(self, *args, **kwargs):
                 self._hub_unavailable()

             def push_to_hub(self, *args, **kwargs):
                 self._hub_unavailable()

             @classmethod
             def from_pretrained(cls, *args, **kwargs):
                 require("huggingface_hub", "Hugging Face Hub integration")
                 raise ImportError(_HUB_IMPORTED_LATE)

         _HUB_AVAILABLE = False
     ```
