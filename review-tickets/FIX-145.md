## Summary

FIX-145: 41 test calls of `select_threshold` and `fit_temperature`, plus the `_fit` helper in `tests/test_calibration.py`, omit `test_split_id`. They emit the new `DeprecationWarning` now and will all break when the argument becomes required in the next minor release. This ticket passes `test_split_id="test"` everywhere except the two tests that omit it on purpose, and adds a `filterwarnings` entry so a new omission fails the suite.

## Context

**What happens today.** For example `tests/test_abstention.py` L498:

```python
    select_threshold(P, Y, kind="margin", risk_ceiling=0.2, split_id="val", labels=LABELS, model_id="m")
```

and the calibration helper (`tests/test_calibration.py` L56–L59), which most calibration tests reach through `_fit()` / `_calibrator()`:

```python
def _fit(logits=K_LOGITS, targets=K_TARGETS, **overrides):
    kwargs = {"labels": BINARY, "model_id": "run-1:BEST", "split_id": "calib", "train_split_id": "train"}
    kwargs.update(overrides)
    return fit_temperature(logits, targets, **kwargs)
```

Only two tests omit the argument on purpose, inside `pytest.warns`: `tests/test_abstention.py::test_selection_without_test_split_id_warns_and_keeps_its_result` (L486) and `tests/test_calibration.py::test_fit_temperature_without_test_split_id_warns_and_fits_as_before` (L993, through `_fit()`). `pyproject.toml` `[tool.pytest.ini_options].filterwarnings` (L258–L273) has no entry for the warning.

**Why it matters.** When the deprecation turns into a required argument, these tests fail in bulk for a reason unrelated to what they test.

**History.** #217 (calibration) and #218 (abstention) wrote these tests before `test_split_id` existed. The finding listed 39 calls; an AST scan of `tests/` at `9ad461e` finds three more that pass their arguments through `**kwargs`: `test_abstention.py` L1217 (`**_declare(name)`), `test_decision_nnx_adapter.py` L394 (`**declared`) and the `_fit` helper.

**Background for the worker.**
- `test_split_id`: the id of the held-out test split; it must differ from `split_id` and `train_split_id`. No call below uses `"test"` for either, so `"test"` is safe everywhere.
- `filterwarnings` in `pyproject.toml`: `"action:message:category:module"`, where `message` is a regular expression matched at the start of the warning text. `pytest.warns(...)` records warnings inside its block regardless of this filter, so the two intentional tests keep passing.
- `None` counts as omitted (`warn_omitted_test_split`), so `_fit(test_split_id=None)` still warns.

**Proposal.**
1. Add the keyword argument `test_split_id="test"` directly after the `split_id=...` argument of each call below (the line is the call's first line at `9ad461e`):
   - `tests/test_abstention.py`, `select_threshold`: L296, L304, L321, L323, L347, L362, L449, L450, L498, L562, L594, L654, L714, L721, L750, L757, L773, L816, L823, L849, L853, L858, L890, L898, L903, L950, L959, L1013, L1050, L1065, L1106, L1217, L1363, L1401 (34 calls; L321, L323, L362, L449, L654, L714, L858, L1050 and L1401 sit inside `pytest.raises`, and each still raises its own error).
   - `tests/test_calibration.py`, `fit_temperature`: L173, L214, L882, L1025.
   - `tests/test_decision_benchmark.py`, `select_threshold`: L1035.
   - `tests/test_decision_jobs.py`, `select_threshold`: L1089.
   - `tests/test_decision_nnx_adapter.py`, `select_threshold`: L394 (put it before `**declared`).

   The call at L1363 ends with `)  # fmt: skip`; keep that marker.
2. `tests/test_calibration.py`, `_fit` (L57): replace the dict with

   ```python
       kwargs = {
           "labels": BINARY,
           "model_id": "run-1:BEST",
           "split_id": "calib",
           "train_split_id": "train",
           "test_split_id": "test",
       }
   ```

   Every `_fit(...)` caller that passes its own `test_split_id` (L98 via `**{field: "shared"}`, L113, L700, L998, L1050) still overrides it.
3. `tests/test_calibration.py::test_fit_temperature_without_test_split_id_warns_and_fits_as_before` (L993): inside its `pytest.warns` block, replace `omitted = _fit()` with `omitted = _fit(test_split_id=None)` so it still omits the argument.
4. `pyproject.toml`, `[tool.pytest.ini_options].filterwarnings`: add after the last entry (L272, `"ignore:The feature will be removed.*:DeprecationWarning:torch.onnx",`):

   ```toml
       # A test that omits test_split_id fails, so none is left behind when it becomes required.
       "error:.*without test_split_id is deprecated:DeprecationWarning",
   ```
5. Run `uv run ruff format tests/` (several one-line calls exceed 120 characters once the argument is added).
6. No CHANGELOG entry: tests and test configuration only.

**Worker setup.** Branch from `develop` after FIX-144 has merged. `uv sync --frozen --all-extras` installs torch and every extra the tests need.
