## Summary

FIX-118: At `alpha=1` with no declared `TaskSpec`, the labels of knowledge distillation are placeholders, so 3ed0133 (#853) made the record carry the loss only. A user who also passes `extra_metrics=` to `train()` then gets no values and no error, so a monitor or early stopping on such a metric never fires. The step cannot tell real labels from placeholders, so this ticket refuses `extra_metrics` in that case, in `kd_train_step_factory`, `feature_kd_train_step_factory` and `kd_objective`. It also corrects the KD docs, which still say every record reports top-1 error and that the teacher is left in eval mode.

## Context

**What happens today.** `kd_train_step_factory`'s step (`src/nnx/paradigms/distillation.py` L170–L218) returns a loss-only record at `alpha == 1` without a task (L208–L211):

```python
        loss_val = finalize_step(loss, ctx, paradigm="distillation")

        if alpha == 1:  # the labels are placeholders the loss never reads: no classification fields to score
            return NNEvaluationDataPoint(loss=loss_val)
```

`feature_kd_train_step_factory`'s step does the same (L394–L397), and so does `KDObjective.__call__` (`src/nnx/objectives.py` L450–L455):

```python
        if self.alpha < 1:  # alpha=1 is pure distillation: the labels are not scored (placeholders train)
            terms = (*terms, _supervised_terms(model, student, Y, "supervised", 1.0 - self.alpha))
        else:
            # Placeholder labels the loss never reads: the record carries the loss alone (no classification fields).
            _check_scorable_target(model.loss_fn, Y, scoring=_KD_OBJECTIVE_SCORING)
            return ObjectiveResult(terms, NNEvaluationDataPoint(loss=ObjectiveResult(terms).loss()))
```

`ctx.extra_metrics` is never consulted on these paths. Dropping accuracy, F1, precision and recall is deliberate: CHANGELOG `[Unreleased]` L16, the docstring (L147–L149) and `tests/test_paradigms_distillation.py::test_alpha_1_scores_no_placeholder_label` (L577–L598). Silently dropping the user's own metrics is not: NNx refuses `extra_metrics` it cannot compute elsewhere (`ranking._no_extra_metrics`, `src/nnx/ranking.py` L577–L582, called first in `RankingObjective.__call__`, L614).

The docs are stale in two more ways (DOC-06):
- `docs/concepts.md` §10.1 L1607 says "EDP reports the combined loss and student top-1 error", false at `alpha=1` without a task; §6.3 L898–L899 says only that `kd_objective(alpha=1)` "scores no labels".
- §10.1 L1601 says the step "puts its net in eval mode** before its forward", and `KDObjective`'s docstring (`objectives.py` L364–L366) says the teacher "is put back in eval mode before every teacher forward"; `feature_kd_train_step_factory`'s docstring (L246–L248) says the same. The code now uses `pinned_eval` (`_step_helpers.py`), which gives each submodule's training flag back after the forward (CHANGELOG L31).

**Why it matters.** Monitors, early stopping and run tables keyed on a user metric silently see nothing. Source: 3ed0133 (#853, "KD placeholders").

**History.**
- #513 (FIX-046) established that "Pure distillation needs placeholder labels, because every batch must hold a target." This ticket keeps that: an `alpha=1` run without `extra_metrics` trains as today (`test_kd_alpha_one_is_pure_distillation` and `test_alpha_1_scores_no_placeholder_label` must pass unchanged).
- #542 (FIX-074) set the refusal style for paradigm steps: refuse a bad configuration with a `ValueError` that names the owner, before it changes anything.

**Background for the worker.**
- `alpha`: the weight of the distillation (soft) term; the hard-label term gets `1 − alpha`. At `alpha=1` the labels are never read by the loss.
- Placeholder labels: dummy targets a pure-distillation batch carries because every batch must hold a target.
- `TaskSpec`: a declared task (categorical, multilabel); with one, the step scores the labels through `m.task_adapter` and `task_record`, which does compute `extra_metrics`. That path is unchanged.
- `extra_metrics`: `NNTrainParams(extra_metrics={name: fn(y_true, y_pred)})`, handed to every step as `ctx.extra_metrics` (`TrainStepContext`, `ObjectiveContext`).
- `pinned_eval(net)`: a context manager that puts `net` in eval mode for the forward and then restores every submodule's `training` flag.

**Proposal.**
1. In `src/nnx/paradigms/distillation.py`, add after `_freeze_teacher` (after L104):

   ```python
   def _refuse_placeholder_metrics(extra_metrics: object, owner: str) -> None:
       """At ``alpha=1`` without a declared task the labels are placeholders the
       loss never reads (#513): ``extra_metrics`` would score them, so they are
       refused instead of silently never called."""
       if extra_metrics:
           raise ValueError(
               f"{owner}(alpha=1) does not score labels without a TaskSpec: extra_metrics would run on placeholder "
               "labels; drop extra_metrics, declare a task, or use alpha < 1"
           )
   ```

2. In `kd_train_step_factory`'s `step` (L170), insert right after `m = ctx.model` (L171), before `_freeze_teacher`:

   ```python
           if alpha == 1 and m.task_adapter is None:  # before anything is frozen, run or updated
               _refuse_placeholder_metrics(ctx.extra_metrics, "kd_train_step_factory")
   ```

3. In `feature_kd_train_step_factory`'s `step` (L313), insert right after `m = ctx.model` (L314):

   ```python
           if alpha == 1 and m.task_adapter is None:  # as kd_train_step_factory: before anything runs
               _refuse_placeholder_metrics(ctx.extra_metrics, "feature_kd_train_step_factory")
   ```

In `src/nnx/objectives.py`, `KDObjective.__call__` (L406): add `_refuse_placeholder_metrics` to a function-local import (`from .paradigms.distillation import _refuse_placeholder_metrics`, beside the existing local imports at L407–L414), and insert right after `model = ctx.model` (L416), before `model.net.train()`:

   - Add at the end of the module:

     ```python
     _PLACEHOLDER_OWNERS = {
         "kd": "kd_train_step_factory(alpha=1)",
         "feature_kd": "feature_kd_train_step_factory(alpha=1)",
         "kd_objective": "kd_objective(alpha=1)",
     }


     @pytest.mark.parametrize("kind", sorted(_PLACEHOLDER_OWNERS))
     def test_alpha_1_refuses_extra_metrics_without_a_task(kind):
         """The labels are placeholders, so a user metric would score them; it was silently never called."""
         set_seed(0)
         teacher, student = _make_classifier(32), _make_classifier(32)
         before = {key: value.clone() for key, value in student.net.state_dict().items()}
         torch.manual_seed(1)
         X, placeholders = torch.randn(16, 8), torch.zeros(16, dtype=torch.long)
         message = re.escape(f"{_PLACEHOLDER_OWNERS[kind]} does not score labels without a TaskSpec")
         with pytest.raises(ValueError, match=message):
             _distill_once(kind, student, teacher, X, placeholders, alpha=1.0, extra_metrics={"x": lambda y, p: 0.0})
         assert all(torch.equal(value, before[key]) for key, value in student.net.state_dict().items())


     @pytest.mark.parametrize("kind", sorted(_PLACEHOLDER_OWNERS))
     def test_a_train_call_with_extra_metrics_at_alpha_1_is_refused_before_any_update(kind, tmp_path, monkeypatch):
         monkeypatch.chdir(tmp_path)
         monkeypatch.setenv("NNX_TQDM_DISABLE", "1")
         set_seed(0)
         teacher, student = _make_classifier(32), _make_classifier(32)
         before = {key: value.clone() for key, value in student.net.state_dict().items()}
         if kind == "kd":
             step = {"train_step_fn": kd_train_step_factory(teacher, alpha=1.0)}
         elif kind == "feature_kd":
             step = {"train_step_fn": feature_kd_train_step_factory(teacher, auxiliary_layers={"layers.0": "layers.0"}, alpha=1.0)}
         else:
             step = {"objective": kd_objective(teacher, alpha=1.0)}
         params = NNTrainParams(
             n_epochs=1,
             train_loader=_classification_loader(n=32, batch_size=16),
             optim=NNOptimParams(name=Optims.SGD, max_lr=0.05, momentum=0.0, weight_decay=0.0),
             extra_metrics={"x": lambda y, p: 0.0},
         )
         with pytest.raises(ValueError, match="extra_metrics would run on placeholder labels"):
             student.train(params=params, **step)
         assert all(torch.equal(value, before[key]) for key, value in student.net.state_dict().items())


     def test_alpha_1_with_a_declared_task_keeps_its_extra_metrics():
         """With a task the labels are real: the task's record computes extra_metrics, and nothing is refused."""
         student, teacher = tasks.categorical(), tasks.categorical(seed=1)
         record = _distill_once("kd", student, teacher, tasks.X, tasks.MIXED, alpha=1.0, extra_metrics={"x": lambda y, p: 0.5})
     ```
