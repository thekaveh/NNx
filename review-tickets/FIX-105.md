## Summary

FIX-105: 3ed0133 (#853) put the sample inputs into a report's `sample_set` digest and added `revisions` / `prompt_identities`, but kept the report format `nnx.decision-benchmark/1`. A report saved by NNx 0.5.0 therefore always fails `compare_reports` against a new report of the same samples, with a false "scored different samples" or "different prompt identities" error. This ticket stamps reports with `report_version: 2` and compares a pre-version report with a newer one on split and metric identity only, with a `UserWarning`.

## Context

**What happens today.** `compare_reports` (`src/nnx/decisions/benchmark.py` L1616–L1625) checks the sample set and the recorded revisions and prompt identities whatever produced the two reports:

```python
    sets = (left.get("sample_set"), right.get("sample_set"))
    if None not in sets and sets[0] != sets[1]:
        raise BenchmarkError(
            f"the reports scored different samples of split {left['split']!r}: {sets[0]} and {sets[1]}"
        )
    # A report without the key recorded no revision or prompt, which is the same as none.
    for key, what in (("revisions", "model revisions"), ("prompt_identities", "prompt identities")):
        recorded = (list(left.get(key) or []), list(right.get(key) or []))
        if recorded[0] != recorded[1]:
            raise BenchmarkError(f"the reports scored with different {what}: {recorded[0]} and {recorded[1]}")
```

Two keys break against a 0.5.0 report:
1. `sample_set`: 0.5.0 wrote `"sha256:" + digest(id, question digest, label, slicing)`; #853 inserted the input digest into each row and kept the `"sha256:"` prefix and `FORMAT = "nnx.decision-benchmark/1"` (L108). The same samples now give a different digest.
2. `revisions` / `prompt_identities`: 0.5.0's `state()` had neither key, which reads as "none". `collect()` has always stamped `prompt_identity` (a digest of `provider.record()`, L628–L636), so for any provider with `record()` (Jev and NLI define it) a new report records one and the 0.5.0 report records none.

**Why it matters.** A user who saved a baseline report with 0.5.0 cannot compare a new run against it, and the error message claims the samples differ when they do not. Source: 3ed0133 (#853).

**History.**
- #243 defined the comparison contract: "Comparison import rejects a mismatched split or metric identity." Split and metric identity are unchanged since 0.5.0 (the `identity` dict, L1278–L1284, is the same), so they stay comparable across versions.
- #762 (DEC-008) is the precedent for an incompatibility with earlier files: its recommended option B kept the new bounds and documented the break in the CHANGELOG. Here the break is avoidable: a version marker lets old reports keep comparing on what they recorded. Plain documentation of the break would be the fallback; it is not chosen.

**Background for the worker.**
- `BenchmarkReport.state()` (L1478–L1492): the plain JSON a report saves (`save`, `to_json`) and `compare_reports` reads. `BenchmarkReport.load_state(path)` returns a saved state and refuses any `format` other than `FORMAT`.
- `_report_state(report)` (L1591–L1598): turns a `BenchmarkReport` or a saved state into the dict `compare_reports` reads; it already refuses a missing `split`, `metric_identity` or `slices`.
- `report_version`: a new integer key. Absent means 1 (NNx 0.5.0 and earlier); 2 means the report's `sample_set` digests the inputs and its `revisions` / `prompt_identities` are recorded.
- `FORMAT` stays `"nnx.decision-benchmark/1"`: changing it would make `load_state` refuse every saved report.
- FIX-104 (which this ticket depends on) added `import warnings` to `benchmark.py` and rewrote the CHANGELOG bullet this ticket extends.

**Proposal.**
1. In `src/nnx/decisions/benchmark.py`, add after `RECORD_FORMAT = "nnx.decision-record/1"` (L109):

   ```python
   # 2: the sample set digests the samples' inputs, and the scored records' revisions and prompt identities are
   # recorded. A report without the key (NNx 0.5.0 and earlier) is version 1.
   REPORT_VERSION = 2
   ```

   Add `"REPORT_VERSION",` to `__all__` directly after `"RECORD_FORMAT",` (L82).
2. In `BenchmarkReport.state()` (L1478), add `"report_version": REPORT_VERSION,` as the second entry of the `state` dict, directly after `"format": FORMAT,`.
3. In `_report_state` (L1591–L1598), replace the final `return dict(state)` with:

   ```python
       version = state.get("report_version", 1)
       if isinstance(version, bool) or version not in (1, REPORT_VERSION):
           raise BenchmarkError(f"a {FORMAT} report has report_version 1 (absent) or {REPORT_VERSION}, got {version!r}")
       return {**state, "report_version": version}
   ```

4. In `compare_reports`, replace the block quoted above (L1616–L1625) with:

   ```python
       if left["report_version"] != right["report_version"]:
           # A report saved before report_version 2 (NNx 0.5.0) digested no sample inputs and recorded no revisions or
           # prompt identities: neither is comparable with a newer report's, so only the checks above apply.
           warnings.warn(
               "compare_reports: one report was saved before NNx recorded sample inputs and revisions; "
               "only its split and metric identity are compared",
               UserWarning,
               stacklevel=2,
           )
       else:
           sets = (left.get("sample_set"), right.get("sample_set"))
           if None not in sets and sets[0] != sets[1]:
               raise BenchmarkError(
                   f"the reports scored different samples of split {left['split']!r}: {sets[0]} and {sets[1]}"
               )
           # A report without the key recorded no revision or prompt, which is the same as none.
           for key, what in (("revisions", "model revisions"), ("prompt_identities", "prompt identities")):
               recorded = (list(left.get(key) or []), list(right.get(key) or []))
               if recorded[0] != recorded[1]:
                   raise BenchmarkError(f"the reports scored with different {what}: {recorded[0]} and {recorded[1]}")
   ```

   Two version-1 reports go through the `else` branch, which is exactly how 0.5.0 compared them: their sample-set digests are comparable with each other, and neither records revisions. Two version-2 reports run the full checks, as today. No error message changes.
5. Replace the `compare_reports` docstring (L1604–L1608) with:

   ```python
       """``b - a`` per slice and metric, for two reports of the same split and
       metric identity, the same model revisions and prompt identities, and —
       when both record it — the same sample set (a :class:`BenchmarkReport` or
       a saved report's state); anything else raises :class:`BenchmarkError`. A
       metric unavailable on either side has no delta.

       A report saved before ``report_version`` 2 (NNx 0.5.0 or earlier) did not
       digest sample inputs or record revisions and prompt identities: compared
       with a newer report, only the split and metric identity are checked,
       with a ``UserWarning``. Two such reports are checked as NNx 0.5.0
       checked them."""
   ```

6. In `docs/decisions.md` §8, replace L660–L661 (the last item of the "Comparison" list):

   Old:
   ```
       - the same sample set (a digest of the samples' ids, questions, inputs,
         labels and slicing), when both reports record it.
   ```
   New:
   ```
       - the same sample set (a digest of the samples' ids, questions, inputs,
         labels and slicing), when both reports record it.

     A report saved by NNx 0.5.0 or earlier (no `report_version`) compares
     with a newer one with a `UserWarning`: only its split and metric
     identity are checked.
   ```

7. Do not change the module docstring here: FIX-106 writes its final text, including this exception.
8. Regenerate the API reference: `uv run python -m scripts.docs.build_api_reference`.
9. CHANGELOG: in `## [Unreleased]` → `### Fixed`, replace the bullet FIX-104 wrote (it starts `- **Benchmark comparisons include sample inputs and record revisions`) with:

   ```
   - **Benchmark comparisons include sample inputs and record revisions, so changed inputs no longer compare as identical.** A sample whose input has no stable digest (a dict holding a NumPy scalar, a list holding NaN, `bytes`, text with a lone surrogate) is still scored: `evaluate` warns (`UserWarning`) and the report records no sample set, so `compare_reports` cannot check that two reports scored the same samples. Reports now carry `report_version: 2`; a report saved by NNx 0.5.0 or earlier compares with a newer one with a `UserWarning`, on its split and metric identity only.
   ```

10. Tests in `tests/test_decision_benchmark.py`. Add `import warnings` to the imports (after `import random`, L17) and `REPORT_VERSION` to the `from nnx.decisions.benchmark import (...)` list (L28–L47). Reuse `fixture()` and `replace` (already imported, L18). Add after `test_report_state_carries_revisions_only_when_records_record_them` (L1339–L1346):

    ```python
    def _saved_by_0_5_0(report):
        """The state NNx 0.5.0 saved for these samples: no report_version, a sample set that digested no input,
        no revisions and no prompt identities."""
        state = report.state()
        del state["report_version"]
        state["sample_set"] = "sha256:" + "0" * 64
        state.pop("revisions", None)
        state.pop("prompt_identities", None)
        return state


    def test_a_report_saved_before_input_digests_compares_with_a_warning():
        samples, records = fixture()
        report = evaluate(samples, [replace(record, prompt_identity="sha256:feed") for record in records], split="x")
        assert report.state()["report_version"] == REPORT_VERSION == 2
        with pytest.warns(UserWarning, match="saved before NNx recorded sample inputs and revisions") as caught:
            deltas = compare_reports(_saved_by_0_5_0(report), report)
        assert [w.filename for w in caught if "saved before" in str(w.message)] == [__file__]
        assert all(delta in (0.0, None) for row in deltas.values() for delta in row.values())
        with pytest.raises(BenchmarkError, match="different splits"):
            compare_reports(_saved_by_0_5_0(report), evaluate(samples, records, split="y"))


    def test_two_reports_saved_before_report_versions_compare_as_0_5_0_did():
        samples, records = fixture()
        old = _saved_by_0_5_0(evaluate(samples, records, split="x"))
        with warnings.catch_warnings():
            warnings.simplefilter("error")
            deltas = compare_reports(old, dict(old))
        assert all(delta in (0.0, None) for row in deltas.values() for delta in row.values())
        other = {**old, "sample_set": "sha256:" + "1" * 64}
        with pytest.raises(BenchmarkError, match="different samples"):
            compare_reports(old, other)


    @pytest.mark.parametrize("version", [3, True, "2", None])
    def test_an_unknown_report_version_is_refused(version):
        samples, records = fixture()
        state = {**evaluate(samples, records, split="x").state(), "report_version": version}
        with pytest.raises(BenchmarkError, match=r"report_version 1 \(absent\) or 2"):
            compare_reports(state, state)
    ```

    `test_sample_set_follows_the_input_text` (L1315), `test_compare_refuses_records_differing_only_in_revision_or_prompt` (L1324–L1336) and `test_report_state_carries_revisions_only_when_records_record_them` (L1339–L1346) stay unchanged and must pass: two current reports keep every check.
