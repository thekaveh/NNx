## Summary

FIX-112: The Hub shape preflight added in ed93d51 (#855) builds the declared module on the meta device before `from_pretrained` builds the real one. For a registered model factory (`ModelSpec`) that runs the user's factory twice per load, with its side effects (downloads, `torch.load`, logging, counters) twice, and even when the meta build then fails. This ticket skips the meta build for registered factories, so they run once and are checked after the build as before #855, and corrects `docs/hub.md`, which also over-states what the preflight protects against.

## Context

**What happens today.** `_declared_module` (`src/nnx/nn/nn_model.py` L1293–L1321) builds a `ModelSpec` through its factory under `torch.device("meta")` (L1303–L1317):

```python
    if isinstance(params.net, ModelSpec):

        def build() -> torch.nn.Module:
            return build_module(params.net)  # type: ignore[arg-type]

    elif isinstance(params.net, Nets) and net_params is not None:

        def build() -> torch.nn.Module:
            return params.net(params=net_params)  # type: ignore[union-attr]
```

`_refuse_shapes_before_build` calls it (L1338) from `from_pretrained` (L4960), which then builds the real module (L4964, `cls(net_params=net_params, params=params, ...)` → `build_module`, L3965). Every successful load of a registered model runs the factory twice. A factory that fails on meta has already run its side effects before `return None`. Built-in `Nets` constructors are pure, so only `ModelSpec` is affected.

`docs/hub.md` §2.3 (L176) also claims: "It also checks the declared shapes on the meta device, so a config asking for a huge network is refused before any memory is allocated." `_refuse_shapes_before_build` refuses only a *mismatch* between the meta module and the `model.safetensors` header; a config and header that agree on a huge network pass, and the network is then allocated.

**Why it matters.** User factories are user code; running them twice doubles downloads and logs and breaks counters. The doc sentence is a safety claim about untrusted artifacts that the code does not keep. Source: ed93d51 (#855).

**History.** #216 (FEAT-006) defined the registered-factory contract: "An unknown factory id or a changed topology raises an error before weights load." That stays true: the post-build check (`check_state_schema`, L4971–L4972) runs before `load_state_dict` (L4973). The module's own reconstruction bookkeeping records "the tensors the descriptor rebuilds, recorded once from the module just built — never a second construction (FEAT-006)" (L3967–L3972); the preflight broke that rule.

**Background for the worker.**
- `ModelSpec(id, version, config, seed)`: names a factory registered with `register_model_factory(id, version, factory)`; `build_module(spec)` resolves and calls it.
- Meta device: `torch.device("meta")` builds modules whose tensors have shapes but no storage, so nothing is allocated.
- Shape preflight: `_refuse_shapes_before_build(weights_path, net_params, params, transforms, excluded, strict, call)` (L1324–L1357) compares the meta module with the safetensors header and refuses a mismatch before the real build. With `_declared_module` returning `None` it returns at once.
- Post-build check: after the real build, `from_pretrained` runs `_refuse_unrecorded_recipe_state` and, for a registered module, `check_state_schema` before `load_state_dict` (L4968–L4973).
- Conflict 4 of the plan: no opt-in `meta_safe` flag; the `ModelSpec` branch returns `None`.

**Proposal.**
1. In `src/nnx/nn/nn_model.py`, `_declared_module`, delete the `ModelSpec` branch (L1303–L1307) and make the `Nets` branch the first, so the body reads:

   ```python
       from ..seeding import _global_rng_kept

       if isinstance(params.net, Nets) and net_params is not None:

           def build() -> torch.nn.Module:
               return params.net(params=net_params)  # type: ignore[union-attr]

       else:
           # A registered factory (ModelSpec) is user code that may download, torch.load or log: it runs once, in
           # the load's real build, which checks its module against the weights before any weight loads.
           return None
       try:
           with torch.device("meta"), _global_rng_kept():
               module = build()
               _replay_transforms(cast(NNModel, SimpleNamespace(net=module, _topology_transforms=())), transforms)
       except Exception:  # the constructor cannot run on meta: the real build raises any real error
           return None
       return module
   ```

2. Replace its docstring (L1296–L1300) with:

   ```python
       """The module a built-in net's config declares, built on the meta device
       so no tensor is allocated, with the recorded topology transforms replayed
       on it as a load replays them. ``None`` for a registered factory
       (``ModelSpec``), which is never run twice, and when the constructor or a
       transform cannot run on meta: the load then builds the network once and
       checks it after the build, before any weight loads."""
   ```

3. Leave `_refuse_shapes_before_build` as it is. Its `if net_params is None and strict: check_state_schema(...)` branch (L1350–L1351) is now unreachable (only a `Nets` module reaches it, and those have `net_params`); FEAT-092 merges the preflight and the load's strict sequence and removes it there.
4. Do not change `build_module`, `register_model_factory` or `from_pretrained`; no `meta_safe` option is added.
5. In `docs/hub.md` §2.3, replace L176:

   Old:
   ```
   Before it builds anything, `from_pretrained` verifies `nnx_hub_manifest.json`: every listed file must exist and match its digest, and paths must stay inside the directory. It also checks the declared shapes on the meta device, so a config asking for a huge network is refused before any memory is allocated. A directory saved before manifests existed still loads, with a `UserWarning`.
   ```
   New:
   ```
   Before it builds anything, `from_pretrained` verifies `nnx_hub_manifest.json`: every listed file must exist and match its digest, and paths must stay inside the directory. For a built-in net it also builds the declared network on the meta device and compares it with the tensor shapes in the `model.safetensors` header, so a config whose shapes do not match its weights is refused before any memory is allocated. A config and header that agree are built as declared, however large. A registered model factory (`ModelSpec`) is never run on the meta device: it runs once, and its module is checked against the weights after the build, before any weight loads; so is a built-in net whose constructor or recorded transforms cannot run on the meta device. Inspect an untrusted `config.json` first. A directory saved before manifests existed still loads, with a `UserWarning`.
   ```

6. CHANGELOG: in `## [Unreleased]` → `### Changed`, replace L13:

   Old:
   ```
   - **`from_pretrained` checks declared shapes before it allocates.** A config whose shapes do not match its weights is refused on the meta device, before the network is built.
   ```
   New:
   ```
   - **`from_pretrained` checks a built-in net's declared shapes before it allocates.** For a built-in net, a config whose shapes do not match its weights is refused on the meta device, before the network is built. A registered model factory (`ModelSpec`) runs once per load; its module is checked against the weights after the build, before any weight loads.
   ```

7. Tests in `tests/test_hub_load_preflight.py`. It imports `json`, `pytest`, `torch`, `NNModel` and `_resign`, `_tiny_model` from `tests.test_hub_mixin` (L5–L12; the import skips the module without the hub extra). `tests/test_hub_mixin.py` defines `_HubEncoder(width=6)` (L315–L321), a `Linear(4, width)` → `Tanh` → `Linear(width, 2)` module. Add at the end of the module:

   ```python
   def test_a_registered_factory_runs_once_per_load(tmp_path):
       """The preflight built a ModelSpec on the meta device and then the load built it again: every load ran the
       user's factory twice, side effects included."""
       from nnx import Losses, ModelSpec, NNModelParams, register_model_factory, unregister_model_factory
       from tests.test_hub_mixin import _HubEncoder

       built_on: list[str] = []

       def factory(config):
           built_on.append(torch.get_default_device().type)
           return _HubEncoder(**config)

       register_model_factory("tests.hub_counted", 1, factory)
       try:
           model = NNModel(params=NNModelParams(net=ModelSpec("tests.hub_counted", 1, {"width": 6}), loss=Losses.CROSS_ENTROPY))
           model.save_pretrained(str(tmp_path))
           built_on.clear()
           loaded = NNModel.from_pretrained(str(tmp_path))
           assert len(built_on) == 1 and built_on[0] != "meta"
           assert isinstance(loaded.net, _HubEncoder)
       finally:
           unregister_model_factory("tests.hub_counted", 1)


   def test_a_registered_factory_whose_topology_changed_is_refused_before_any_weight_loads(tmp_path, monkeypatch):
       """#216: a changed topology raises before weights load. Without the meta build, the post-build check refuses it."""
       from nnx import Losses, ModelSpec, NNModelParams, register_model_factory, unregister_model_factory
       from tests.test_hub_mixin import _HubEncoder

       register_model_factory("tests.hub_reshaped", 1, lambda config: _HubEncoder(**config))
       try:
           model = NNModel(params=NNModelParams(net=ModelSpec("tests.hub_reshaped", 1, {"width": 6}), loss=Losses.CROSS_ENTROPY))
           model.save_pretrained(str(tmp_path))
           register_model_factory("tests.hub_reshaped", 1, lambda config: _HubEncoder(width=12), replace=True)
           loads: list[str] = []
           original = torch.nn.Module.load_state_dict

           def recording_load(self, *args, **kwargs):
               loads.append(type(self).__name__)
               return original(self, *args, **kwargs)

           monkeypatch.setattr(torch.nn.Module, "load_state_dict", recording_load)
           with pytest.raises(ValueError, match="topology does not match the saved weights") as caught:
               NNModel.from_pretrained(str(tmp_path))
           assert "refused before the network was built" not in str(caught.value)  # the post-build check, not the preflight
           assert loads == []
       finally:
           unregister_model_factory("tests.hub_reshaped", 1)
   ```

   `test_a_config_declaring_huge_dimensions_is_refused_before_the_network_is_allocated` (L24–L44) and `test_a_mismatch_is_refused_before_the_network_is_built_on_a_real_device` (L47–L66) cover built-in nets and must pass unchanged.
