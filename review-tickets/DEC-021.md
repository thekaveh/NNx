## Summary

DEC-021: NNx has no stated policy for the permission bits of the files it writes. Four Hub/Ollama writers, the partial-file exports and #859's atomic `torch.save` (PEFT adapter files, the nets' `to_file`) get the mode a plain `open()` gives, while every other atomic writer, including user-requested exports such as calibrators, split manifests and `export_history_csv`, leaves `mkstemp`'s 0600. The owner must pick one rule: user exports plain and run files private (A), everything private (B) or everything plain (C).

## Context

**What happens today.** The text writer creates its temporary file with `tempfile.mkstemp`, which is 0600, and only some callers widen it (`src/nnx/nn/params/nn_run.py` `_atomic_write_text`, L233–L234 and L268–L270):

```python
    directory = os.path.dirname(os.path.abspath(path))
    fd, tmp = tempfile.mkstemp(prefix=f".{os.path.basename(path)}.", dir=directory)
```

```python
        if mode is not None:
            os.chmod(tmp, mode)
        os.replace(tmp, path)
```

FIX-116 (BUG-12 + BUG-13) replaces `mode` with `plain_mode: bool = False`, adds `_create_exclusive(directory, prefix, suffix, mode)` (an `O_CREAT | O_EXCL` create under the current umask), and makes `_commit_partial` keep an existing destination's mode, else rely on the umask applied at create time. FIX-116 does not change which call sites use plain mode; that policy is this ticket. No doc or CHANGELOG states which files get which mode.

**Why it matters.** The same kind of file (a JSON artifact a user saves to share) is 0644 from one function and 0600 from another, and nothing says which to expect.

**History.**
- #849 (582c08a) introduced the plain mode for the four Hub/Ollama writers with the comment "the mode a plain write gave before this path was atomic" (`nn_model.py` L4780, `generative_nn_model.py` L71).
- #260 (FIX-025) set the atomic text writer's cleanup contract; #552 its flush contract. Neither recorded a permission policy. Every option keeps both contracts (`tests/test_atomic_write_text.py`).

**Background for the worker.**
- umask: the process-wide mask the kernel clears from a new file's requested mode; `open(path, "w")` requests 0666, so under umask 022 the file is 0644. `mkstemp` requests 0600, so its files are private whatever the umask.
- `_atomic_write_text(path, content, *, plain_mode=False)` (after FIX-116): writes through a temporary file and `os.replace`; `plain_mode=True` creates the temporary with 0666 through `_create_exclusive`, so the umask applies.
- `_artifacts.atomic_write(path, text)`: a thin wrapper over `_atomic_write_text` used by `JsonArtifact.save` and the record writers.
- `_artifacts.atomic_torch_save(obj, path)`: the atomic `torch.save` #859 added; after FIX-150 it writes through `_reserve_partial` / `_commit_partial`, so its files follow whatever mode `_reserve_partial` creates.
- `JsonArtifact`: base class of NNx's JSON artifacts (`_artifacts.py` L135–L170); `save` writes `to_json()` atomically.

## Options

| Option | What changes | Trade-off |
|---|---|---|
| A (recommended) | Files a caller saves to a path they name (T1–T13, P1–P3) get plain mode; files inside `runs/<id>/` and checkpoint files (R1–R6) stay 0600. Nine writers (T5–T13) change. | Matches what a plain `open()` gave these exports and keeps run files, which hold environment snapshots and provenance, private. Two rules to remember. |
| B | Everything NNx creates is 0600 (T1–T4 and P1–P3 change). | One rule, and nothing is ever readable by other users. A shared Hub directory or ONNX file needs a manual `chmod`. |
| C | Everything NNx creates follows the umask (T5–T13 and R1–R6 change; `plain_mode` goes away). | One rule, like most tools. Run directories, including provenance and environment snapshots, become readable by other users under the common umask. |

A is recommended because the four writers #849 made plain did so to keep the mode users had before, the same reasoning applies to every other export, and run files hold the environment snapshot that should stay private.

4. Test, in `tests/test_atomic_write_text.py` (add `import stat` if absent):

   ```python
   @pytest.mark.skipif(os.name == "nt", reason="POSIX permission bits")
   def test_user_exports_get_the_plain_mode_and_run_files_stay_private(tmp_path):
       from nnx._artifacts import atomic_write
       from nnx.decisions.benchmark import write_records
       from nnx.preprocessing import Standardizer

       old = os.umask(0o022)
       try:
           atomic_write(tmp_path / "export.json", "{}\n", plain_mode=True)
           atomic_write(tmp_path / "internal.json", "{}\n")
           Standardizer.fit([[1.0], [3.0]], rows=[0, 1], dtype="float64").save(tmp_path / "standardizer.json")
           write_records(tmp_path / "records.jsonl", [])
       finally:
           os.umask(old)

       def mode(name):
           return stat.S_IMODE((tmp_path / name).stat().st_mode)

       assert mode("export.json") == mode("standardizer.json") == mode("records.jsonl") == 0o644
       assert mode("internal.json") == 0o600  # the default, which run files use
   ```
