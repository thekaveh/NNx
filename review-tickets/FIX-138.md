## Summary

FIX-138: Three leftovers of the split of `docs/quickstart.md` into a minimal page and `docs/quickstart-recipes.md`. The recipes page numbers its sections from §2.2 with no note why; README §6.1 still describes Quickstart as "a runnable example with variations" and links neither the recipes nor two other guides `docs/index.md` lists; and the README quickstart code has drifted from `docs/quickstart.md`. This ticket adds a numbering note (option (a) of the finding), fixes the README list, and makes the two code blocks identical.

## Context

**What happens today.**
- `docs/quickstart-recipes.md` L1 is `# 3. Quickstart recipes`, and its first heading is `## 2. Common variations` / `### 2.2. Precision…` (no §2.1). The sections continue `docs/quickstart.md`'s §2 (which holds §2.1 and links "sections 2.2 to 2.22 and … section 3", L65). Cross-references such as "Quickstart recipes §3.10" depend on that numbering, so the page is not renumbered.
- `README.md` L328: `- [Quickstart](docs/quickstart.md) — a runnable example with variations to copy and adapt.` README §6.1 (L326–L340) never links Quickstart recipes, Export conformance or Feature composition; `docs/index.md` L69, L93 and L94 list them.
- `README.md` §3 (L129–L168) differs from `docs/quickstart.md` L9–L51 in four places: README omits `seed=42` and `grad_clip_norm=1.0`, spaces `torch.randn(64, 8),  torch.randint` differently, and ends with `logits, classes = model.predict(X=X_val.numpy())` where the guide has `result = model.predict(X=X_val)` and a `print`.

**Why it matters.** The README is the PyPI page (`PYPI_README.md` is generated from it), so the first code a user copies differs from the guide's, and two guides are unreachable from it.

**History.** #472 repaired the documentation surfaces and set the rule that they agree. #262 (the decision-model pilot) was closed as not planned, so its page stays out of the README list.

**Background for the worker.**
- `PYPI_README.md` is generated from `README.md`: run `uv run python -m scripts.docs.build_pypi_readme` after editing, never edit it by hand.
- Doc headings are numbered on every page except `CHANGELOG.md`.

**Proposal.**
1. `docs/quickstart-recipes.md`: insert after L1 (`# 3. Quickstart recipes`) one blank line and:

   ```
   Sections continue [Quickstart](quickstart.md)'s numbering: §2.2–§2.22 and §3.
   ```
2. `README.md` §6.1, replace L328:

   Old: `- [Quickstart](docs/quickstart.md) — a runnable example with variations to copy and adapt.`

   New (two lines):
   ```
   - [Quickstart](docs/quickstart.md) — a runnable minimal example.
   - [Quickstart recipes](docs/quickstart-recipes.md) — the variations and recipes beyond supervised classification.
   ```
3. `README.md` §6.1, insert after L340 (the `- [External dependency contracts](docs/external-contracts.md) — …` line):

   ```
   - [Export conformance](docs/export-conformance.md) — what an ONNX export record proves, profile by profile.
   - [Feature composition](docs/feature-composition.md) — which feature combinations are verified, refused or unverified.
   ```

   (descriptions copied from `docs/index.md` L93–L94).
4. `README.md` §3 code block: make it identical to `docs/quickstart.md` L9–L51 with these four edits (line numbers before any edit):
   - L142: Old `X_val,   y_val   = torch.randn(64, 8),  torch.randint(0, 3, (64,))` → New `X_val,   y_val   = torch.randn(64,  8), torch.randint(0, 3, (64,))`
   - after L155 (`    n_epochs=10,`), insert `    seed=42,                       # reproducibility`
   - L159: Old `                        momentum=(0.9, 0.999), weight_decay=5e-5),` → New, two lines: `                        momentum=(0.9, 0.999), weight_decay=5e-5,` and `                        grad_clip_norm=1.0),`
   - L167: Old `logits, classes = model.predict(X=X_val.numpy())  # returns PredictResult(logits=..., classes=...)` → New, two lines: `result = model.predict(X=X_val)` and `print(f"predicted {len(result.classes)} samples")`
5. Regenerate the PyPI README: `uv run python -m scripts.docs.build_pypi_readme`.

**Worker setup.** No torch needed (docs/config only).
