## Summary

FIX-135: Four Hub texts lag the code. `docs/hub.md` §2.1 lists the save layout without `nnx_hub_manifest.json` and `tokenizer.json`; the `_from_pretrained` docstring describes the load path before manifests and the shape preflight; the Hub row of `docs/external-contracts.md` names neither contract nor their tests; and `docs/hub.md` §1.2 omits what `to_file(format="safetensors")` refuses. This ticket corrects all four, with exact old and new text.

## Context

**What happens today.**
- `docs/hub.md` L105 (§2.1): ``this writes (`model.safetensors` + `config.json` + `README.md`) is what``. The code also writes `nnx_hub_manifest.json` (`nn_model.py` L4783) and, for a `GenerativeNNModel`, `tokenizer.json` (`generative_nn_model.py` L61–L73). §2.2 (L158) already lists the manifest.
- `NNModel._from_pretrained` docstring (`nn_model.py` L4812–L4817) says it reads `config.json` "via their public ``from_state`` constructors, then load[s] ``model.safetensors``". The code verifies the manifest first (`_verify_hub_manifest`, L4904), rebuilds the net params with `NNParams.resolve_from_state` (L4944) and preflights the shapes (`_refuse_shapes_before_build`, L4960).
- `docs/external-contracts.md` L27, the Hub row, lists "`PyTorchModelHubMixin` and safetensors checkpoint APIs" and two test files. Its review rule (L136–L137) says to update the ledger with any published-format change.
- `docs/hub.md` §1.2 (L46–L75) does not say that `to_file(format="safetensors")` refuses a runtime-only module, a recorded transform NNx cannot replay, and a record value JSON cannot hold; its docstring (`nn_checkpoint.py` L576–L593) does.

**Why it matters.** Users and reviewers read the guide and the ledger, not the code; both now describe a narrower contract than the one shipped.

**History.** #767 (DEC-013) decided that `to_file(format="safetensors")` refuses unreplayable transforms (option C, shipped in 0.4.4) but no guide was updated; DOC-22 is that leftover. #509 made `save_pretrained` refuse the same content and is the wording §1.2 follows. The manifest and preflight came with ed93d51 (#855).

**Background for the worker.**
- `nnx_hub_manifest.json`: the file `save_pretrained` writes last, holding the SHA-256 and size of every saved file; `from_pretrained` verifies it before building anything, and a directory without one loads with a `UserWarning`.
- Shape preflight: `from_pretrained` builds the declared network on the meta device (no memory) and compares its shapes with the tensor shapes in the `model.safetensors` JSON header.
- `_from_pretrained` is private, so it is not in `docs/api.md`; no regeneration is needed for it.

**Proposal.**
1. `docs/hub.md` §2.1, replace L105:

   Old: ``this writes (`model.safetensors` + `config.json` + `README.md`) is what``

   New (two lines):
   ```
   this writes (`model.safetensors` + `config.json` + `nnx_hub_manifest.json` +
   `README.md`, plus `tokenizer.json` for a `GenerativeNNModel`) is what
   ```
2. `src/nnx/nn/nn_model.py`, `NNModel._from_pretrained` docstring, replace L4812–L4817:

   Old:
   ```
           Dispatched-to by :meth:`PyTorchModelHubMixin.from_pretrained`,
           which handles the remote-download path before calling this. Local
           paths skip the download. Either way, we read ``config.json`` to
           reconstruct the net params and ``NNModelParams`` via their public
           ``from_state`` constructors, then load ``model.safetensors`` into
           the freshly-built ``self.net``.
   ```
   New:
   ```
           Dispatched-to by :meth:`PyTorchModelHubMixin.from_pretrained`,
           which handles the remote-download path before calling this. Local
           paths skip the download. Either way, we verify
           ``nnx_hub_manifest.json`` (a directory without one loads with a
           ``UserWarning``), rebuild the net params with
           ``NNParams.resolve_from_state`` and ``NNModelParams`` with
           ``from_state``, check the declared shapes against the weights'
           header on the meta device (when the net can be built there), then
           build ``self.net`` and load ``model.safetensors`` into it.
   ```
3. `docs/external-contracts.md`, replace the Hub row (L27):

   Old:
   ```
   | Hugging Face Hub | `huggingface-hub>=1.4.0` / `2.4.0`; `safetensors>=0.7.0` / `0.8.0` | `PyTorchModelHubMixin` and safetensors checkpoint APIs | `tests/test_hub_mixin.py` and `tests/test_checkpoint_safetensors.py`; authenticated pushes are intentionally credential-gated. |
   ```
   New:
   ```
   | Hugging Face Hub | `huggingface-hub>=1.4.0` / `2.4.0`; `safetensors>=0.7.0` / `0.8.0` | `PyTorchModelHubMixin` and safetensors checkpoint APIs; the NNx `nnx_hub_manifest.json` (SHA-256 and size per file) and the safetensors JSON header read for shape preflight | `tests/test_hub_mixin.py`, `tests/test_checkpoint_safetensors.py`, `tests/test_hub_manifest.py`, `tests/test_hub_load_preflight.py` and `tests/test_hub_export_atomic.py`; authenticated pushes are intentionally credential-gated. |
   ```
4. `docs/hub.md` §1.2, insert after L75 (`same KeyboardInterrupt-safety guarantee that the pickle path provides.`) one blank line and:

   ```
   A runtime-only module (`MissingModelFactoryError`), a recorded transform NNx
   cannot replay from data (`ValueError`, as `save_pretrained` refuses it) and a
   record value JSON cannot hold (`TypeError`) are refused before anything is
   written; keep such a checkpoint as `format="pickle"`.
   ```

**Worker setup.** No torch needed (docs/config only).
